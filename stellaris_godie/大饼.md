# 群星：虚空挑战 — 更新计划

> 当前版本：v0.0.1

本文记录点子，暂不考虑可行性

---

## 近期重点

### 舰船按钮主动技能

- 继续使用舰船组件 `scripted_action` 做主动技能按钮。
- 利用按钮 tooltip 的实时动态文本显示技能状态、冷却、等级、经验等数据。
- 优先围绕母舰和英雄舰实现技能，不扩散到所有普通舰船，避免逐舰事件和变量刷新过重。
- 技能按钮图标保持稳定，状态变化主要通过 tooltip 文本反馈。

### 成长性英雄舰

- 为单艘英雄舰建立等级和经验变量。
- 按钮文本实时显示：
    - 等级：`X级`
    - 经验值：`xxx/xxx`
    - 当前成长加成
    - 下一级奖励预览
- 通过战斗、击杀、Boss奖励、流派奖励等来源增加英雄舰经验。
- 升级后刷新英雄舰或所在舰队的成长型 buff。
- 先做母舰或一艘核心英雄舰验证机制，再扩展到多英雄舰。

### 二级流派系统重做

- 二级时不再只给通用流派奖励，而是允许玩家选择一艘英雄舰船。
- 英雄舰专精某个方向后，后续奖励池围绕英雄舰与普通舰队构建展开。
- 二级选择应影响：
    - 后续奖励池权重
    - 可出现的主动技能
    - 成长型 buff 类型
    - 普通舰队构筑方向
- 奖励池需要同时支持英雄舰强化和普通舰队协同，避免玩家只强化单船或只堆普通舰队。

### 可扩展流派方向

- 成长型 buff 流派：英雄舰随等级获得持续属性、光环或舰队加成。
- 召唤流英雄舰：英雄舰主动技能召唤护航舰、无人机或临时舰队。
- 火控辅助流：强化命中、追踪、索敌、射程和舰队协同。
- 回复维护流：强化船体、装甲、护盾恢复和战后整备。
- 献祭流：牺牲低价值舰船换取英雄舰或全舰队短期爆发。
- 精英舰队流：少量高质量舰船获得成长层数和强力协同。
- 数量流：围绕低成本舰船、免费舰队和召唤舰队形成压制。

## Boss系统

- **变量动态Boss选择**：Boss非开局固定，而是游戏进程中根据玩家行为累积房主国家上的虚空倾向变量，缩圈到最终阶段时从房主国家读取变量并调整Boss候选池权重。
    - 征服（`br_void_conquest`）：击杀、战斗、精英舰队 -> 无畏战舰、远古堡垒等。
    - 湮灭（`br_void_oblivion`）：爆星、毁灭星球、掠夺资源 -> 噬星者、虚空孳孽等。
    - 献祭（`br_void_sacrifice`）：舰船损失、牺牲舰队、以损失换收益 -> 位面之魇、幽魂等。
    - 进化（`br_void_evolution`）：等级提升、科技强化、母舰进化 -> 无限神机、机械化Boss等。
    - 禁忌（`br_void_taboo`）：强力但有代价的效果、污染交易、危险改造 -> 虚境化身、恶堕化身等。
- 最终Boss选择事件必须在 `event_target:br_pve_alliance_leader` 作用域下读取这些变量，避免读取到普通玩家国家的空变量。
- **隐藏Boss解锁**：扭曲意识、异次元传送门、虚境显圣等需要特定 flag 组合才能解锁进入候选池。
- **多Boss随机池**：当前仅实现单模板Boss（`BR_PVE_BOSS`），需扩展为21种Boss加权随机选择，详见 `Boss设计-虚空挑战.md`。
- **Boss战特殊机制**：阶段转换、召唤小怪、特殊技能等。
- **小Boss机制**：缩圈途中随机区域刷出次级Boss，击杀给特殊奖励。
- **Boss奖励差异化**：每个Boss击杀掉落不同的虚空遗物，用于母舰或英雄舰强化树解锁。

## 刷怪系统

- **区域差异化刷怪**：当前所有区域刷同样类型的怪，需改为边缘轻型、中层混合、核心重型。
- **随机跳区域刷新**：特殊事件刷出精英怪群。
- **精英模板扩展**：为不同流派敌军增加精英舰队模板和特殊舰队词条。
- **多人强度缩放**：继续完善基于所有玩家总舰船战斗力的敌方强度加成。

---

## 成长系统

- **PVE专属科技树或母舰强化树**：用虚空遗物解锁强化。
- **英雄舰等级系统**：用舰船按钮和动态 tooltip 显示等级、经验和升级需求。
- **成长型 modifier 分档**：按等级或专精刷新不同静态 modifier，避免无限叠加。
- **经验来源整合**：战斗、击杀、爆星、Boss奖励和特殊事件都应能进入统一经验逻辑。

## 玩家舰队构建

核心机制：不是开局选流派直接成型，而是在游戏过程中通过战斗、爆星、事件获得奖励碎片，逐步组合自己的流派。每局随机出什么碎片就拼什么流派，类似肉鸽构筑。

奖励碎片类型示例：

- **武器模块**：射程、伤害、射速、穿透等属性强化。
- **舰船模块**：减造价、减建造时间、免费舰船等。
- **全局 buff**：击杀触发效果、光环类效果、吸血等。
- **特殊能力**：献祭、召唤、自爆等一次性或循环能力。
- **英雄舰模块**：主动技能、等级成长、专精强化、英雄舰光环。

| 流派        | 核心碎片组合                      | 可行性                                 |
|-----------|-----------------------------|-------------------------------------|
| 远距狙击流     | 射程+、命中+、单发伤害+、索敌范围+         | 武器/计算机 modifier 可控                  |
| 近战爆发流     | 短程伤害+、护盾冲锋+、护甲穿透+、闪避+       | modifier + 计算机行为                    |
| 航母流       | 舰载机伤害+、舰载机数量+、出击冷却-         | 舰载机冷却大幅缩短需 component 修改             |
| 数量流       | 舰船造价-、建造时间-、免费舰船事件、伤害-      | `ship_cost_mult` + `create_ship` 事件 |
| 精英 buff 流 | 击杀叠层、层数上限、每层效果、层数衰减         | `on_ship_killed` 触发，注意性能            |
| 献祭叠数值流    | 低价值舰船快速建造、销毁触发 buff、目标舰船属性+ | 需要事件链检测舰船销毁                         |
| 免费舰队流     | 定时 `create_ship`、舰队容量+、维护费- | 纯事件机制，原版已验证                         |
| 吸血恢复流     | 击杀回HP、击杀回盾、脱战恢复+            | `on_ship_killed` + `repair_ship`    |
| 英雄召唤流     | 英雄舰主动技能、临时召唤舰队、召唤物强化        | 适合按钮技能和等级系统                         |
| 英雄成长流     | 英雄舰等级、分档 buff、专精奖励池         | 适合二级流派重做                            |
