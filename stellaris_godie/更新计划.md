# 群星：虚空挑战 — 更新计划

> 当前版本：v0.0.1

---

## 核心概念

虚空正在侵蚀这个星系。玩家作为残存势力的联军，从被侵蚀的边缘星域出发，一路向内推进，途中通过战斗和爆星获取资源、拼凑流派，最终在星系中心挑战被虚空腐化的终极Boss。

本质上是**变相的肉鸽爬塔模式**——每局从零开始，奖励随机，流派自组。

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        成长循环                                         │
│                                                                         │
│   战斗 → 获得 combat_score → 提升 power_level → 解锁更强奖励         │
│   爆星 → 获得大量资源 → 建造更强舰队 → 往里推                          │
│   奖励碎片 → 逐步组合流派 → 形成构筑 → 挑战Boss                        │
└─────────────────────────────────────────────────────────────────────────┘

边缘（虚空侵蚀区）   中层（沦陷区）      核心（重灾区）      中心（虚空之源）
┌────────────┐    ┌────────────┐    ┌────────────┐    ┌──────────┐
│ 联军残部    │    │ 杂兵舰队     │    │ 精英舰队     │    │ 最终Boss  │
│ 初始舰队    │ ←─ │ 边打边撤    │ ←─ │ 精锐尽出     │ ←─ │         │
│ 构筑起点    │ 毒圈 │ 拼凑流派    │ 毒圈 │ 构筑成型     │ 毒圈 │ +精英卫队  │
└────────────┘    └────────────┘    └────────────┘    └──────────┘
```

毒圈从外向内不断收缩，玩家边战边退向中心。战斗中通过奖励碎片逐渐拼凑出自己的流派构筑，爆星获取资源补充舰队，越战越强，最终在中心面对终极Boss。

## 完整PVE开局流程

目标流程不再依赖玩家原始出生点，也不再先创建后传送，PVE从一开始就围绕边缘出生和向中心推进设计喵

1. 进入游戏后由房主先弹出所有开局设置窗口，包括速度、模式、后续敌方模板等选项喵
2. 所有设置完成后先执行扩圈事件，标记中心、圈层和实际最大扩展范围喵
3. 扩圈完成后根据模式进入初始化分流，PVP暂时只保留扩展口，不在当前阶段实现具体逻辑喵
4. PVE模式为每个玩家从当前地图实际最外圈随机挑选出生星系，小地图会自动从最大已扩展圈层向内回退喵
5. 玩家标准国家、母舰、护卫舰队和舰队司令直接创建在选中的边缘出生点，省去原出生点创建再传送的步骤喵
6. 玩家分配完成后创建PVE敌对国家，并一次性生成普通敌方舰队，越靠近中心敌方数量和强度越高喵
7. 正常游玩阶段由战斗、爆星、奖励事件和资源兑换推动玩家构筑流派喵
8. 缩圈进入最终圈后再由独立Boss事件读取过程变量和选择倾向，生成最终Boss和护卫舰队喵

事件职责边界喵

- `br_settings_events.txt`：只负责开局设置和设置完成后的流程入口喵
- `br_expand_events.txt`：只负责扩圈、圈层标记和初始安全区状态喵
- `br_start_events.txt`：负责玩家标准国家创建、地图清理、PVP/PVE模式初始化分流喵
- `br_pve_events.txt`：负责PVE边缘出生点选择和普通敌方舰队初始化喵
- `br_pve_boss_events.txt`：负责最终Boss生成、Boss击杀检测和胜利奖励喵

当前PVE事件编号顺序喵

- `br.530`：选择PVE边缘出生点喵
- `br.531`：初始化普通敌方舰队喵
- `br.532`：最终圈生成Boss和护卫舰队喵
- `br.533`：Boss死亡检测后设置胜利状态喵
- `br.534`：胜利弹窗和终局奖励喵

## 待实现

### Boss系统

- **变量动态Boss选择**（核心机制）：Boss非开局固定，而是游戏进程中根据玩家行为累积房主国家上的虚空倾向变量，缩圈到最终阶段时从房主国家读取变量并调整Boss候选池权重
  - 征服（`br_void_conquest`）：击杀、战斗、精英舰队 → 无畏战舰、远古堡垒等
  - 湮灭（`br_void_oblivion`）：爆星、毁灭星球、掠夺资源 → 噬星者、虚空孳孽等
  - 献祭（`br_void_sacrifice`）：舰船损失、牺牲舰队、以损失换收益 → 位面之魇、幽魂等
  - 进化（`br_void_evolution`）：等级提升、科技强化、母舰进化 → 无限神机、机械化Boss等
  - 禁忌（`br_void_taboo`）：强力但有代价的效果、污染交易、危险改造 → 虚境化身、恶堕化身等
  - 最终Boss选择事件必须在 `event_target:br_pve_alliance_leader` 作用域下读取这些变量，避免读取到普通玩家国家的空变量
- **隐藏Boss解锁**：扭曲意识、异次元传送门、虚境显圣等需要特定flag组合才能解锁进入候选池
- **多Boss随机池**：当前仅实现单模板Boss（`BR_PVE_BOSS`），需扩展为21种Boss加权随机选择（详见 `Boss设计-虚空挑战.md`）
- **Boss战特殊机制**：阶段转换、召唤小怪、特殊技能等
- **小Boss机制**：缩圈途中随机区域刷出次级Boss，击杀给特殊奖励
- **Boss奖励差异化**：每个Boss击杀掉落不同的虚空遗物，用于母舰强化树解锁

### 刷怪系统

- **区域差异化刷怪**：当前所有区域刷同样类型的怪，需改为边缘轻型/核心重型
- **随机跳区域刷新**：特殊事件刷出精英怪群

### 成长系统

- **PVE专属科技树** 或 **母舰强化树**：用虚空遗物解锁强化

### 玩家舰队构建（肉鸽式渐进组合）

**核心机制**：不是开局选流派直接成型，而是在游戏过程中通过战斗/爆星/事件获得的奖励碎片，逐步组合出自己的流派。每局随机出什么碎片就拼什么流派，类似肉鸽的构筑逻辑。

奖励碎片类型示例：

- **武器模块**：射程、伤害、射速、穿透等属性强化
- **舰船模块**：减造价、减建造时间、免费舰船等
- **全局buff**：击杀触发效果、光环类效果、吸血等
- **特殊能力**：献祭、召唤、自爆等一次性/循环能力

| 流派          | 核心碎片组合                          | 可行性                                   |
|-------------|---------------------------------|---------------------------------------|
| **远距狙击流**   | 射程+ + 命中+ + 单发伤害+ + 索敌范围+       | ✅ 武器/计算机modifier可控                    |
| **近战爆发流**   | 短程伤害+ + 护盾冲锋+ + 护甲穿透+ + 闪避+     | ✅ modifier+计算机行为                      |
| **航母流**     | 舰载机伤害+ + 舰载机数量+ + 出击冷却-         | ⚠️ 舰载机冷却大幅缩短需component修改              |
| **数量流（人海）** | 舰船造价- + 建造时间- + 免费舰船事件 + 伤害-    | ✅ `ship_cost_mult` + `create_ship` 事件 |
| **精英buff流** | 击杀叠层 + 层数上限 + 每层效果 + 层数衰减       | ⚠️ `on_ship_killed` 触发，注意性能           |
| **献祭叠数值流**  | 低价值舰船快速建造 + 销毁触发buff + 目标舰船属性+  | ⚠️ 需要事件链检测舰船销毁                        |
| **免费舰队流**   | 定时 `create_ship` + 舰队容量+ + 维护费- | ✅ 纯事件机制，原版已验证                         |
| **吸血恢复流**   | 击杀回HP + 击杀回盾 + 脱战恢复+            | ✅ `on_ship_killed` + `repair_ship`    |
