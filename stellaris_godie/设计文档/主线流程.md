# 群星：虚空挑战 — 主线流程草案

---

## 核心概念

虚空正在侵蚀这个星系。玩家作为残存势力的联军，从被侵蚀的边缘星域出发，一路向内推进，途中通过战斗和爆星获取资源、拼凑流派，最终在星系中心挑战被虚空腐化的终极Boss。

本质上是变相的肉鸽爬塔模式：每局从零开始，奖励随机，流派自组。

```text
┌─────────────────────────────────────────────────────────────────────────┐
│                        成长循环                                         │
│                                                                         │
│   战斗 -> 获得 combat_score -> 提升 power_level -> 解锁更强奖励         │
│   爆星 -> 获得资源/科技 -> 建造更强舰队 -> 往里推                        │
│   奖励碎片 -> 逐步组合流派 -> 形成构筑 -> 挑战Boss                      │
└─────────────────────────────────────────────────────────────────────────┘

边缘（虚空侵蚀区）   中层（沦陷区）      核心（重灾区）      中心（虚空之源）
┌────────────┐    ┌────────────┐    ┌────────────┐    ┌──────────┐
│ 联军残部    │    │ 杂兵舰队     │    │ 精英舰队     │    │ 最终Boss  │
│ 初始舰队    │ <- │ 边打边撤    │ <- │ 精锐尽出     │ <- │         │
│ 构筑起点    │ 毒圈 │ 拼凑流派    │ 毒圈 │ 构筑成型     │ 毒圈 │ +精英卫队  │
└────────────┘    └────────────┘    └────────────┘    └──────────┘
```

毒圈从外向内不断收缩，玩家边战边退向中心。战斗中通过奖励碎片逐渐拼凑自己的流派构筑，爆星获取资源补充舰队，越战越强，最终在中心面对终极Boss。

---

## 完整PVE开局流程

1. 进入游戏后由房主先弹出所有开局设置窗口，包括速度、模式、后续敌方模板等选项。
2. 所有设置完成后先执行扩圈事件，标记中心、圈层和实际最大扩展范围。
3. 扩圈完成后根据模式进入初始化分流，PVP暂时只保留扩展口，不在当前阶段实现具体逻辑。
4. PVE模式为每个玩家从当前地图实际最外圈随机挑选出生星系，小地图会自动从最大已扩展圈层向内回退。
5. 玩家标准国家、母舰、护卫舰队和舰队司令直接创建在选中的边缘出生点，省去原出生点创建再传送的步骤。
6. 玩家分配完成后创建PVE敌对国家，并一次性生成普通敌方舰队，越靠近中心敌方数量和强度越高。
7. 正常游玩阶段由战斗、爆星、奖励事件和资源兑换推动玩家构筑流派。
8. 缩圈进入最终圈后再由独立Boss事件读取过程变量和选择倾向，生成最终Boss和护卫舰队。

---

## 局内主循环

1. 玩家在边缘出生，获得母舰和初始护卫舰队。
2. 敌方舰队按圈层强度分布，玩家向内推进。
3. 击杀、战斗和爆星产生局内分数、资源和奖励事件。
4. 奖励碎片逐步推动舰队构筑成型。
5. 缩圈持续压缩活动空间，迫使玩家向中心移动。
6. 最终圈生成Boss和精英卫队。
7. 击杀Boss后结算胜利奖励。
