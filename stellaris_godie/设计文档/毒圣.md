# 毒圣 设计文档

> 毒圣（TYPE = toxic_god，Toxoids DLC 守护者）的定位与备选方向。已实装，数值与实现细节以代码为准；通用框架见 `利维坦系统.md`。

## 定位与主题

腐蚀消耗型巨兽：原版设定是从剧毒星云中诞生的活体神明，躯体是一张不断开合的巨口。战斗定位是腐蚀消耗——先削弱敌人的护甲与武器（腐蚀之雾），再压制敌人的恢复能力（瘟疫扩散），自身靠再生与厚甲立于不败。没有爆发，但任何舰队在它的星域里都撑不过第二轮毒雾。

## 已实装指针

- 技能（槽 1/2/3）：腐蚀之雾 / 毒沼披覆 / 瘟疫扩散，实装于 `common/scripted_actions/lev_toxic_god_actions.txt` 与 `common/static_modifiers/lev_toxic_god_buffs.txt`；数值随成长等级动态，基准见 `common/script_values/lev_skill_values.txt`（lev_sk_toxic_*）。
- 每级成长：`LEV_TOXIC_GOD_CORE`（`common/component_templates/lev_cores.txt`），`mult = owner.lev_toxic_god_growth_level`；船体再生成长字段为 `ship_hull_regen_add_static`（0.015/级，定值口径）。
- 第 4 支援技能：孢子沃土（行星支援，`lev_toxic_god_support`，见 `common/scripted_actions/lev_support_actions.txt` 与 `events/lev_support_events.txt`）。
- planet_killer 槽保留在区段（`PLANET_KILLER_GUN_01`），玩家设计器装不上杀灭武器，未来做「毒化行星」可直接复用。
- 模型链：`lev_toxic_god_mesh` 引用原版 toxic_god.mesh，动画注册自建 lev_toxic_god_ 前缀（idle/moving/opening/open/closing/attack/death，含 closed/opened 两个死亡态）；开合状态机与毒雾副实体照抄原版。事件 lev.1500~1502（`events/lev_toxic_god_events.txt`）。
- 获取：解锁法令（`common/edicts/lev_unlock_edicts.txt`，置 `lev_toxic_god_unlocked`）+ 调试折跃（`events/lev_debug_events.txt`）。

## 备选方向（未实装）

1. 瘟疫扩散可叠加「敌舰经验获取降低」，无现成 ship 级字段，需到 country 级曲线救国。
2. 毒沼披覆可换成反伤机制（受击反弹毒伤），引擎无直接反伤字段，需 on_hit 链 + damage_ship。
3. 未来开放 planet_killer 武器（毒化行星：pop 受毒害 debuff）时，区段槽已就位，只需新增组件与 on_destroy_planet_with_* on_action。
4. 减益可考虑改为「在星域内持续刷新」（毒云滞留），需要循环 on_action 或 planet 级 modifier 载体。
