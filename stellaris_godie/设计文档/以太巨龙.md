# 以太巨龙（利维坦）具体方案

> 以太巨龙（TYPE = drake）的定位、设计取舍与踩坑记录。已实装，数值与实现细节以代码为准；通用框架见 `利维坦系统.md`，换色专题见 `以太巨龙-换色方案.md`。

## 定位

利维坦系统 V1 参考实现：先用一条龙跑通「克隆 ship_size + 区段 + 技能 + 获取线 + 本地化」全流程，作为后续利维坦的模板。军事型定位，不配行星支援。换色：固定红（原版 Ether Drake 外观，自制 lev_drake_entity 克隆链），D6 决策详情见 `以太巨龙-换色方案.md`。

## 已实装指针

- 技能（槽 1/2/3）：龙息喷吐 / 龙翼护体 / 焚世吐息，实装于 `common/scripted_actions/lev_drake_actions.txt` 与 `common/static_modifiers/lev_drake_buffs.txt`；数值随成长等级动态，基准见 `common/script_values/lev_skill_values.txt`（lev_sk_drake_*）。
- 每级成长：`LEV_DRAKE_CORE`（`common/component_templates/lev_cores.txt`），`mult = owner.lev_drake_growth_level`。
- 文件：`lev_ship_sizes.txt` / `lev_drake_sections.txt` / `lev_drake.gfx` / `lev_drake.asset`（gfx/models/ships/guardians/drake/）/ `lev_drake_component_sets.txt` / `lev_drake_on_actions.txt` / `lev_drake_events.txt`（lev.1100~1199）。
- 获取：解锁法令 `lev_unlock_drake`（`common/edicts/lev_unlock_edicts.txt`，置 flag + lev_growth_init）+ 调试折跃 lev.3300（`events/lev_debug_events.txt`）；DLC 门槛 `host_has_dlc = "Leviathans Story Pack"`。设计文档原写的通用收复线框架（Phase 0-3）未实装。

## 设计取舍（引擎限制调研）

* 龙息喷吐原案「敌舰受伤 +60%」：引擎没有直接提高敌方所受伤害的 ship 类 modifier 字段，改用「敌舰武器伤害 -25% / 射速 -15%」等效。
* 龙翼护体原案「仇恨 +1」：引擎无对应字段，省略；「自身减伤 +20%」以 `ship_armor_mult +40%` 近似承载。
* 焚世吐息原案「直接伤害 + 护盾/护甲压制」：不做直接伤害，用减益等效。
* 原案大招B（巨龙狂暴）、被动A/B（龙鳞装甲、龙威光环）未实装：龙鳞装甲方向并入每级成长，龙威光环的负面光环效果并入龙息喷吐。

## 实现记录踩坑（V1）

* 模型链：`lev_drake_mesh` 引用原版 `guardian_01_space_dragon.mesh`，meshsettings（红龙贴图 + PdxMeshAlphaAdditive / PdxMeshShip 双材质）逐字照抄；动画文件直接指向原版 `.anim`（idle/moving/death/attack 四条），不复制文件。
* 区段槽位名：mod 版用 `invisible_medium_turret_fixed`（不是任务书写的 `invisible_medium_fixed`，以原版 `component_slot_templates` 实际定义为准）；PD 槽 `invisible_point_defence_turret`；XL 槽沿用 `invisible_extra_large_fixed`。
* 事件作用域：on_action 触发的事件里 `THIS = from = 施放舰队`，敌舰减益通过 `solar_system = { every_ship_in_system = { limit = { is_hostile = event_target:lev_caster } } }` 批量施加；施放国先存为事件目标 `lev_caster`。
* 手感取原版以太巨龙（max_speed 110 / 加速 0.4 / 转速 0.5 / 碰撞半径 8）。
