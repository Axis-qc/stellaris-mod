# 以太巨龙（利维坦）具体方案

> 本文件是「利维坦系统」下**以太巨龙**的**具体数值 / 技能 / 获取方案**（V1 参考实现）。
> 通用框架与技能组设计方法论见 `利维坦系统.md`；换色专题见 `以太巨龙-换色方案.md`。
> 数值基准：`数值设计规范.md`。

---

## 一、定位

- 利维坦系统 V1 参考实现：先用一条龙跑通「克隆 ship_size + 区段 + 6 技能 + 获取线 + 本地化」全流程，作为后续利维坦的模板。
- 模型：原版以太巨龙（`space_dragon_red_entity` / `space_dragon_red_section_entity`），复用 §2.2 清单。
- 换色：默认红（原版 Ether Drake 外观），是否随机 / 按文化 / 固定见 `以太巨龙-换色方案.md`（决策项 D6）。

## 二、技能组（V1 实装版本）

**主题：烈焰吐息 / 龙威压制 / 装甲巨兽**

本期实装 3 个主动技能（槽 1/2/3），不做直接伤害效果（引擎无「敌方受伤加深」类 modifier 字段，统一用减益等效；原案中含伤害的部分见下表「原案」栏）。被动不做二选一切换，常驻属性并入核心组件的每级成长。

| 槽位 | 技能 | 效果（本期实装） | 冷却 | 持续 |
|---|---|---|---|---|
| 1 | 龙息喷吐 | 本星系敌舰武器伤害 -25%、射速 -15%；自身射速 +20% | 180天 | 20天 |
| 2 | 龙翼护体 | 自身护甲 +40%（`ship_armor_mult`）、船体再生 +2%/天（`ship_hull_regen_add_perc`） | 240天 | 30天 |
| 3 | 焚世吐息 | 本星系敌舰武器伤害 -35%、护盾回复 -50%（`ship_shield_regen_mult`）、减速 30%（`ship_speed_mult`） | 480天 | 40天 |

原案与差异说明：

* 龙息喷吐原案「敌舰受伤 +60%」：引擎没有直接提高敌方所受伤害的 ship 类 modifier 字段，改用「敌舰武器伤害 -25% / 射速 -15%」等效实现。
* 龙翼护体原案「仇恨 +1」：引擎无对应字段，本期省略；「自身减伤 +20%」以 `ship_armor_mult +40%` 近似承载。
* 焚世吐息原案「300 范围直接伤害 + 护盾/护甲压制 2000」：本期不做直接伤害，用减益等效（伤害 -35%、护盾回复 -50%、减速 30%）。
* 原案中的大招B（巨龙狂暴）、被动A/B（龙鳞装甲、龙威光环）本期未实装；龙鳞装甲方向并入每级成长，龙威光环的负面光环效果并入龙息喷吐。

## 三、成长方向（每级，乘以成长等级）

装甲巨兽方向，与《利维坦系统.md》§4.2 一致：

| 属性 | 字段 | 每级 |
|---|---|---|
| 船体 | `ship_hull_add` | +600 |
| 护甲 | `ship_armor_add` | +800 |
| 武器伤害 | `ship_weapon_damage` | +2% |
| 船体再生 | `ship_hull_regen_add_perc` | +1% |

成长属性由核心组件 `LEV_DRAKE_CORE` 的 `triggered_ship_modifier`（`mult = owner.lev_drake_growth_level`）承载；数值天花板以《数值设计规范》强度天花板（单技能 ≤5× 原版、总 DPS ≤15×）校准。

### 实现记录（V1）

* 模型链：`lev_drake_mesh` 引用原版 `guardian_01_space_dragon.mesh`，meshsettings（红龙贴图 + PdxMeshAlphaAdditive / PdxMeshShip 双材质）逐字照抄原版 `space_dragon_red_mesh`；动画文件直接指向原版 `.anim`（idle/moving/death/attack 四条），不复制文件。
* 区段：原版龙的 medium 槽用 `medium_turret`（会渲染金属炮塔），mod 版全部换成 `invisible_medium_turret_fixed`（该名称与任务书写的 `invisible_medium_fixed` 不同，以原版 `component_slot_templates` 实际定义为准）；PD 槽用 `invisible_point_defence_turret`；XL 槽沿用原版的 `invisible_extra_large_fixed`。
* 船体手感取原版以太巨龙（`max_speed = 110`，加速 0.4，转速 0.5，碰撞半径 8），比噬星者（90/0.25/0.2/15）明显更快更灵活。
* 技能本期无资源门槛（`possible`/`button_clickable` = `always = yes`），不引用 begin/progress/finish 动画状态，避免引用未注册动画。
* 事件作用域：on_action 触发的事件里 `THIS = from = 施放舰队`，敌舰减益通过 `solar_system = { every_ship_in_system = { limit = { is_hostile = event_target:lev_caster } } }` 批量施加；施放国先存为事件目标 `lev_caster`（噬星者 `lev_stellarite_effects.txt` 同款写法）。
* 实机验证项（主控统一接线后跑）：`is_hostile` 在 `every_ship_in_system` 内的判定、成长变量 `lev_drake_growth_level` 的接线。
