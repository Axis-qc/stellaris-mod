# 幽魂（利维坦）具体方案

> 幽魂（TYPE = wraith，原版 Leviathans Story Pack 的 Wraith）的定位与备选方向。已实装，数值与实现细节以代码为准；通用框架见 `利维坦系统.md`。

## 定位 / 主题

相位：维度间的能量生命体，打的是「看得见、摸不着」——高闪避 + 高机动的游击型，大招把相位乱流灌进整个星系瘫痪敌舰火控。与龙的差异：龙走厚甲重击，幽魂走闪避机动 + 高频输出；船体数值成长最低，但闪避与伤害成长独一档。

## 已实装指针

- 技能（槽 1/2/3）：光谱穿刺 / 光影残像 / 辉光风暴，实装于 `common/scripted_actions/lev_wraith_actions.txt` 与 `common/static_modifiers/lev_wraith_buffs.txt`；数值随成长等级动态，基准见 `common/script_values/lev_skill_values.txt`（lev_sk_wraith_*）。
- 每级成长：`LEV_WRAITH_CORE`（`common/component_templates/lev_cores.txt`），`mult = owner.lev_wraith_growth_level`。
- 第 4 支援技能：光谱校准（行星支援，`lev_wraith_support`，见 `common/scripted_actions/lev_support_actions.txt` 与 `events/lev_support_events.txt`）。
- 模型链：`lev_wraith_mesh` 引用原版 `wraith_01.mesh`（蓝幽魂贴图）；原版幽魂只有 idle/moving/death 三个动画，无 attack，mod 版同样不注册。事件 lev.130~139（`events/lev_wraith_events.txt`）。
- 获取：解锁法令（`common/edicts/lev_unlock_edicts.txt`，置 `lev_wraith_unlocked`）+ 调试折跃（`events/lev_debug_events.txt`）。

## 备选方向（未实装）

* 光谱穿刺追加「无视护盾」：直接伤血（引擎无穿透字段，需伤害事件 + effect 组合）。
* 光影残像追加「残影仇恨」：强制敌舰把幽魂设为目标（引擎无 taunt 字段，需 `ship_target_weight_mult` 提高受击权重近似，原版字段已确认存在）。
* 辉光风暴追加「敌舰 FTL 干扰」：禁止星系内敌舰逃逸（依赖星系级 situation / 干扰字段）。
