## 二、技能倍率系统

### 2.1 倍率公式

所有技能效果受两套倍率同时放大：

```
等级乘区    = hero_level × 0.1
独立乘区    = br_skill_N_mult_player（默认 0，可被临时效果修改）
最终倍率    = 1 + 等级乘区 + 独立乘区
```

```
敌方强度倍率 = 1 + (玩家总数 - 1) × 0.3
```

## 十、平衡调整原则

### 10.1 强度天花板

- **单技能最大效果**：不超过原版舰船基础属性的 5 倍
- **叠加后理论极限**：不超过原版的 15 倍 DPS
- **Boss存活时间**：满配玩家应在 60-120 天内击败Boss

### 10.2 下限保底

- **无技能英雄舰**：应能单挑战列舰 ×3
- **最低等级（Lv1）**：应能存活于第2圈普通战斗
- **缩圈保底**：每次缩圈给予基础资源补给

### 10.3 核心平衡

- **输出核心**（火力/献祭）：DPS 最高，但生存较弱
- **生存核心**（防御/支援）：生存最强，但 DPS 较低
- **功能核心**（机动/控制/航母）：特定场景极强，通用性稍弱
- **经济核心**（掠夺/命运）：资源优势明显，但风险较高
- **协同核心**（指挥）：单人较弱，多人极强
