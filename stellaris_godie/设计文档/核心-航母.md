# 航母核心（Carrier）— 舰载机 / 编队制空 / 多舰种协同向

> **⚠ 纯设计文档，尚未实现。**

## 核心定位

航母核心专注于舰载机作战与多舰种协同。选航母就是选"掌控天空"——舰队中不同舰种在航母体系下发挥独特作用，舰队规模直接影响航母战斗力。

## 关键实现约束

英雄舰（`br_vanguard`）**无法合并外来舰船**到自己的舰队中，所有召唤单位以独立舰队形式在星系内协同作战。

## 无人机设计（当前方案）

航母核心召唤的无人机 **直接复制玩家当前的护卫舰设计**（`design = NAME_Dagger`），使用玩家已解锁的科技和武器，相当于额外的免费护卫舰。

```
create_ship = { name = random design = NAME_Dagger }
```

> **未来可升级**：后续可新增自定义 `br_carrier_drone` ship_size，替换 `NAME_Dagger` 以获得独立数值控制和专属外观。

## 核心机制一：航母常驻舰队

航母核心拥有 **专属常驻舰队**（标记 `br_carrier_fleet`），在第一次使用技能时创建，此后所有技能只往这支舰队里补船，不清空、不销毁。舰船在战斗中自然损失，技能负责补充。

## 核心机制二：无人机数量由英雄舰决定

无人机舰队的总上限直接取决于英雄等级，在技能事件中用变量计算：

```
# 在技能事件中
set_variable = { which = br_carrier_cap value = owner.br_hero_level }
multiply_variable = { which = br_carrier_cap value = 2 }    # 上限 = 英雄等级 × 2
```

| 英雄等级 | 无人机上限 |
|:-------:|:---------:|
| Lv2 | 4 艘 |
| Lv6 | 12 艘 |
| Lv12 | 24 艘 |

所有补船技能只需检查当前舰队 **缺多少补多少**，用 `br_carrier_cap` 变量作上限比对。

## 核心机制三：舰队增幅无人机质量

星系内每艘友军舰船都会为无人机舰队提供战斗加成，鼓励航母核心玩家 **保持舰队在身边**：

| 舰种 | 每艘提供加成 | 战术含义 |
|------|------------|---------|
| 护卫舰（corvette） | 命中 **+2** | 前出侦察，引导无人机锁定 |
| 驱逐舰（destroyer） | 追踪 **+2** | 区域防空雷达，辅助无人机追踪 |
| 巡洋舰（cruiser） | 闪避 **+1%** | 电子战支援，干扰敌方火控 |
| 战列舰（battleship） | 减伤 **+1%** | 战略平台，为无人机提供防御场 |

**加成上限**：各舰种最多计算 10 艘（共最多 40 艘，上限充足）。

**实现方式**：星系级 `every_ship_in_system` 统计各舰种数量（同 `br_crisis_grunt_spawn_effects.txt` 模式），然后直接对无人机舰队施加 modifier。

```
# 统计
solar_system = {
    set_variable = { which = br_carrier_buff_corvette value = 0 }
    set_variable = { which = br_carrier_buff_destroyer value = 0 }
    set_variable = { which = br_carrier_buff_cruiser value = 0 }
    set_variable = { which = br_carrier_buff_battleship value = 0 }
    every_ship_in_system = {
        limit = { exists = owner owner = { is_same_value = root.owner } }
        if = { limit = { AND = { is_ship_size = corvette check_variable = { which = br_carrier_buff_corvette value < 10 } } }
            change_variable = { which = br_carrier_buff_corvette value = 1 } }
        if = { limit = { AND = { is_ship_size = destroyer check_variable = { which = br_carrier_buff_destroyer value < 10 } } }
            change_variable = { which = br_carrier_buff_destroyer value = 1 } }
        if = { limit = { AND = { is_ship_size = cruiser check_variable = { which = br_carrier_buff_cruiser value < 10 } } }
            change_variable = { which = br_carrier_buff_cruiser value = 1 } }
        if = { limit = { AND = { is_ship_size = battleship check_variable = { which = br_carrier_buff_battleship value < 10 } } }
            change_variable = { which = br_carrier_buff_battleship value = 1 } }
    }
}

# 对无人机舰队施加 modifier（参考防御核心 heroship.1203 模式，直接 add_modifier 在 fleet）
random_owned_fleet = {
    limit = { has_fleet_flag = br_carrier_fleet }
    add_modifier = { modifier = br_carrier_enhance_corvette mult = br_carrier_buff_corvette days = 31 }
    add_modifier = { modifier = br_carrier_enhance_destroyer mult = br_carrier_buff_destroyer days = 31 }
    add_modifier = { modifier = br_carrier_enhance_cruiser mult = br_carrier_buff_cruiser days = 31 }
    add_modifier = { modifier = br_carrier_enhance_battleship mult = br_carrier_buff_battleship days = 31 }
}
```

> 变量名直接用于 `mult`（参考 `heroship.1200` 的 `mult = value:br_skill_phase_shift_dmgreduct` 模式），变量值即为倍率。

## 主动技能（Lv2 二选一）

### ① 编队出击 — 补充无人机

向常驻航母舰队补充无人机 **至上限**：

* 补到 `br_carrier_cap` 艘为止
* 冷却 **120 天**（受 `cdmult` 强化）
* 补入的舰船为常驻单位，战斗自然消耗

**实现方式**：

```
# 1. 确保常驻舰队存在（首次使用）
if = {
    limit = { NOT = { any_owned_fleet = { has_fleet_flag = br_carrier_fleet } } }
    create_fleet = {
        name = "BR_CARRIER_FLEET"
        effect = {
            set_owner = root.owner
            set_location = { target = solar_system distance = 0 }
            set_fleet_flag = br_carrier_fleet
        }
    }
}

# 2. 计算上限（国家作用域）
owner = {
    set_variable = { which = br_carrier_cap value = br_hero_level }
    multiply_variable = { which = br_carrier_cap value = 2 }
}

# 3. 统计现有，用 owner.变量 补到上限
random_owned_fleet = {
    limit = { has_fleet_flag = br_carrier_fleet }
    set_variable = { which = br_carrier_cur_total value = 0 }
    every_ship_in_fleet = { change_variable = { which = br_carrier_cur_total value = 1 } }
    while = {
        count = owner.br_carrier_cap
        if = {
            limit = { check_variable = { which = br_carrier_cur_total value < owner.br_carrier_cap } }
            create_ship = { name = random design = NAME_Dagger }
            change_variable = { which = br_carrier_cur_total value = 1 }
        }
    }
}

# 4. 设置冷却
owner = {
    set_variable = { which = br_vanguard_carrier_skill_cd value = 0 }
    change_variable = { which = br_vanguard_carrier_skill_cd value = value:br_carrier_sortie_cd }
    if = {
        limit = { NOT = { has_country_flag = br_vanguard_skill_cd_tick_running } }
        set_country_flag = br_vanguard_skill_cd_tick_running
        country_event = { id = heroship.1014 days = 1 }
    }
}
```

### ② 防空阵型 — 分层防御网络

按舰种分配防空任务，各自获得针对性强化：

| 舰种 | 加成效果（基础值 × sk1_mult） |
|------|---------------------------|
| 护卫舰（corvette） | 闪避 **+15** |
| 驱逐舰（destroyer） | 点防伤害 **+50%**，追踪 **+15** |
| 巡洋舰（cruiser） | 舰载机伤害 **+30%** |
| 战列舰（battleship） | 舰载机射速 **+30%** |

持续 **20 天**（受 `daymult` 强化）。
冷却 **180 天**（受 `cdmult` 强化）。

**实现方式**：使用星系级 `every_fleet_in_system` + `add_modifier` 为不同舰种施加不同 modifier（参考防御核心 `heroship.1200` 模式）。

```
solar_system = {
    every_fleet_in_system = {
        limit = { exists = owner owner = { NOT = { is_hostile = root.owner } } }
        add_modifier = {
            modifier = br_carrier_aat_cv       # 每种舰种独立 modifier
            mult = value:br_skill_aat_mult
            days = 1
            time_multiplier = value:br_skill_aat_day
        }
    }
}
```

## 被动技能（Lv4 二选一，可切换）

通过英雄舰 UI 随时切换当前激活的被动技能。切换时自动交换对应的 `_unlocked` 标记。

### ③ 制空权（Lv4）— 舰队增幅无人机

被动解锁 **核心机制三：舰队增幅**。星系内友军舰船按舰种为无人机舰队提供战斗加成：

| 舰种 | 每艘提供 | 10艘时总计 | 战术含义 |
|------|--------:|----------:|---------|
| 护卫舰 | 命中 **+2** | +20 | 前出侦察，引导锁定 |
| 驱逐舰 | 追踪 **+2** | +20 | 防空雷达，辅助追踪 |
| 巡洋舰 | 闪避 **+1%** | +10% | 电子战支援 |
| 战列舰 | 减伤 **+1%** | +10% | 战略防御平台 |

所有加成受 `sk2_mult` 倍率强化。常驻生效，每 30 天月脉冲刷新。

**不选此被动则无舰队增幅**，无人机只有基础能力。

---

### ④ 甲板维护（Lv4）— 自动补给 + 质量强化

与制空权共用被动槽，**可随时切换**。选此技能时放弃舰队增幅，换取无人机自维持能力。

**自动补给**：每 **30 天** 自动向航母常驻舰队补充 **1 艘** 无人机（直到总数达 `br_carrier_cap`）。
**质量强化**：航母舰队舰船获得船体 **+50% × sk2_mult**，武器伤害 **+25% × sk2_mult**。

常驻生效（质量强化用 `add_modifier` 施加，`mult = value:br_hero_ship_skill_2_mult` 动态缩放）。

常驻生效。

**实现方式**：
* 自动补给：在月脉冲事件中检查航母舰队总数，低于上限则 `create_ship` 补 1 艘
* 质量强化：对常驻舰队施加永久 modifier，补船后刷新

```
# 月脉冲补给逻辑
if = {
    limit = { has_country_flag = br_skill_deck_maintenance_unlocked }
    owner = {
        set_variable = { which = br_carrier_cap value = br_hero_level }
        multiply_variable = { which = br_carrier_cap value = 2 }
    }
    random_owned_fleet = {
        limit = { has_fleet_flag = br_carrier_fleet }
        set_variable = { which = br_carrier_cur_total value = 0 }
        every_ship_in_fleet = { change_variable = { which = br_carrier_cur_total value = 1 } }
        if = {
            limit = { check_variable = { which = br_carrier_cur_total value < owner.br_carrier_cap } }
            create_ship = { name = random design = NAME_Dagger }
        }
        # 刷新舰队增幅 modifier
        add_modifier = { modifier = br_carrier_enhance_corvette mult = br_carrier_buff_corvette days = 31 }
        add_modifier = { modifier = br_carrier_enhance_destroyer mult = br_carrier_buff_destroyer days = 31 }
        add_modifier = { modifier = br_carrier_enhance_cruiser mult = br_carrier_buff_cruiser days = 31 }
        add_modifier = { modifier = br_carrier_enhance_battleship mult = br_carrier_buff_battleship days = 31 }
    }
}
```

## 大招（Lv6 二选一）

### ⑤ 全甲板攻击 — 饱和出击

立即向常驻航母舰队一次性补满无人机至上限，同时提升全队舰载机作战效能：

* 补满到 `br_carrier_cap` 艘
* 同时全队舰载机伤害 **+75% × sk3_mult**，射速 **+75% × sk3_mult**（星系级 modifier，持续 60 天）
* 冷却 **360 天**（受 `cdmult` 强化）

**实现方式**：
* 补船逻辑同编队出击（常驻舰队 + 补到上限）
* 舰载机加成用 `every_fleet_in_system` + `add_modifier` + `time_multiplier`

---

### ⑥ 绝对制空 — 战场空中封锁

英雄舰启动绝对制空领域：

* 友军舰载机伤害 **+100% × sk3_mult**，速度 **+100% × sk3_mult**
* 敌方舰载机效率 **-75% × sk3_mult**，导弹伤害 **-50% × sk3_mult**

持续 **30 天**（受 `daymult` 强化）。
冷却 **480 天**（受 `cdmult` 强化）。

**实现方式**：
* 友方加成：星系级 `every_fleet_in_system` + `add_modifier`
* 敌方 debuff：星系级 `every_fleet_in_system` + `limit = { is_hostile = root.owner }` + debuff modifier
* 使用 modifier：
  * `weapon_type_strike_craft_weapon_damage_mult`（舰载机伤害）
  * `weapon_type_strike_craft_speed_mult`（舰载机速度）
  * `weapon_type_strike_craft_weapon_damage_mult` 负值（敌方舰载机效率降低）
  * `weapon_type_explosive_weapon_damage_mult` 负值（敌方导弹伤害降低）

## 技能联动系统

联动效果根据 **当前激活的被动技能** 决定。由于被动可随时切换，联动链也可在战斗中动态调整。

### 联动链 A — 制空权 + 大招

**触发条件**：当前激活 **制空权** + 任一航母大招

* **通用效果**：大招激活期间，舰队增幅效果 **翻倍**（每艘舰种提供的命中/追踪/闪避/减伤 ×2）
* **全甲板攻击专属**：大招期间无人机额外获得 **+25% × sk3_mult** 武器伤害
* **绝对制空专属**：大招期间舰队增幅不再需要友舰在场，**满额常驻生效**

### 联动链 B — 甲板维护 + 大招

**触发条件**：当前激活 **甲板维护** + 任一航母大招

* **通用效果**：大招激活期间，甲板维护的自动补给频率提升至 **每 15 天** 补 1 艘（原30天），且质量加成翻倍（船体 **+100% × sk3_mult**，伤害 **+50% × sk3_mult**）
* **全甲板攻击专属**：补船数量 **+50% × sk3_mult**
* **绝对制空专属**：无额外补船，但友军舰载机速度加成翻倍
