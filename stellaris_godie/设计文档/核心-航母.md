# 航母核心（Carrier）— 舰载机 / 编队制空 / 多舰种协同向

> **✅ 已实现，2026-06-02 技能重做。**

## 核心定位

航母核心专注于**无人机作战与制空权争夺**。选航母就是选"掌控天空"——无人机舰队的规模直接受英雄等级影响，通过技能维持空中优势，同时通过射程光环支援主力舰队。

## 关键实现约束

英雄舰（`br_vanguard`）**无法合并外来舰船**到自己的舰队中，所有召唤单位以独立舰队形式在星系内协同作战。

## 无人机设计（当前方案）

航母核心召唤的无人机 **直接复制玩家当前的护卫舰设计**（`design = NAME_Dagger`），使用玩家已解锁的科技和武器，相当于额外的免费护卫舰。

```
create_ship = { name = random design = NAME_Dagger }
```

> **未来可升级**：后续可新增自定义 `br_carrier_drone` ship_size，替换 `NAME_Dagger` 以获得独立数值控制和专属外观。

## 核心机制一：航母常驻舰队

航母核心拥有 **专属常驻舰队**（标记 `br_carrier_fleet`），在第一次使用技能时创建，此后所有技能只往这支舰队里补船，不清空、不销毁。舰船在战斗中自然损失，技能负责补充。

## 核心机制二：无人机数量由英雄舰决定

无人机舰队的总上限直接取决于英雄等级，在技能事件中用变量计算：

```
# 在技能事件中
set_variable = { which = br_carrier_cap value = owner.br_hero_level }
multiply_variable = { which = br_carrier_cap value = 2 }    # 上限 = 英雄等级 × 2
```

| 英雄等级 | 无人机上限 |
|:-------:|:---------:|
| Lv2 | 4 艘 |
| Lv6 | 12 艘 |
| Lv12 | 24 艘 |

所有补船技能只需检查当前舰队 **缺多少补多少**，用 `br_carrier_cap` 变量作上限比对。

## 核心机制三：射程光环（被动）

选择被动 **④ 制空权** 后激活。根据星系内无人机数量，给所有友军舰船加射程：

| 无人机数量 | 射程加成 | 战术含义 |
|:---------:|:--------:|---------|
| 5 艘 | +5% | 小规模编队，略有优势 |
| 10 艘 | +10% | 满编时最大化优势 |

加成受 `sk2_mult` 倍率强化，月度脉冲由 1335 刷新。

**不选此被动则无射程光环**，无人机只提供火力输出。

## 技能选择

* Lv2（主动×2选1）：**编队出击 / 无人机增强**
* Lv4（被动×2选1）：**甲板维护 / 制空权**
* Lv6（大招×2选1）：**全甲板攻击 / 绝对制空**

---

## 主动技能（Lv2 二选一）

### ① 编队出击 — 应急补充

向常驻航母舰队补充 `hero_level` 艘无人机，**可超上限**。

* 补充数量等于**当前英雄等级**（Lv2=2艘，Lv6=6艘，Lv12=12艘）
* 可超出 `br_carrier_cap` 上限——超出的船不会消失，但月度自动补船仍只补到上限
* 冷却 **120 天**（受 `cdmult` 强化）

**设计意图**：快速爆兵应对突发战损。超上限的额外船是临时优势，后续靠自然战损回落到常规水平。

**实现方式**：利用现有 1331→1332→1333 月度链，设 `br_carrier_full_replenish` flag，并在 1332 中将 `br_carrier_deficit` 设为 `hero_level`（而不是 `cap - count`）。

---

### ② 无人机增强 — 火控强化

给常驻无人机舰队施加 **命中 + 追踪** buff：

* 全队 `ship_accuracy_add` + **15 × sk1_mult**
* 全队 `ship_tracking_add` + **15 × sk1_mult**
* 持续 **20 天**（受 `daymult` 强化）
* 冷却 **180 天**（受 `cdmult` 强化）

**实现方式**：`fleet_event` → `event_target:br_void_country` → `random_owned_fleet`（`has_fleet_flag = br_carrier_fleet_@root`）→ `add_modifier`：

```
add_modifier = {
    modifier = br_carrier_drone_accuracy
    mult = root.owner.value:br_skill_1_mult
    days = 1
    time_multiplier = root.owner.value:br_skill_1_daymult
}
```

---

## 被动技能（Lv4 二选一，可切换）

通过英雄舰 UI 随时切换当前激活的被动技能。切换时自动交换对应的 `_unlocked` 标记。

### ③ 甲板维护（Lv4）— 加速补给

**月度补给速率**提升：

* 基础每月补 **1** 艘
* 每级英雄等级额外 +**1** 艘（Lv4=4艘/月，Lv12=12艘/月）
* 受 `sk2_mult` 倍率强化

**不选此被动则月度只补 1 艘**。

**实现方式**：在 1332 的补给速率计算中，检查 `br_skill_deck_maintenance_unlocked`，将 `br_carrier_supply_count` 改为 `hero_level`（而非旧版的固定+1/+2）。

---

### ④ 制空权（Lv4）— 射程光环

根据星系内 **无人机数量** 给同星系 **友军舰船** 加射程：

* 每有 **5 艘无人机**，友舰 `ship_weapon_range_add` **+5%**
* 上限：**10 艘无人机 = +10%** 射程
* 受 `sk2_mult` 倍率强化
* 月度脉冲刷新

**设计意图**：不选此被动则无人机只提供火力输出，选它后无人机本身也成为战术资产——拉开阵型的越多，全队射程越远。

**实现方式**：在 1335（原制空权位置）中，直接读 `br_carrier_count` 变量，计算阶梯：

```
event_target:br_hero_system_@root = {
    every_fleet_in_system = {
        limit = {
            exists = owner
            owner = { OR = { is_same_value = root is_country_type = br_player_pve } }
        }
        add_modifier = {
            modifier = br_carrier_range_aura
            mult = root.value:br_carrier_range_mult
            days = 32
        }
    }
}
```

## 大招（Lv6 二选一）

### ⑤ 全甲板攻击 — 饱和打击

召唤一支 **独立临时舰队**（不标记 `br_carrier_fleet`，不影响主舰队），持续一段时间后自动消失：

* 召唤 `hero_level × 3` 艘无人机（Lv6=18艘，Lv12=36艘）
* 持续 **60 天**，到期后整队自毁
* 临时舰队携 **+50% × sk3_mult** 伤害加成
* 冷却 **360 天**（受 `cdmult` 强化）

**设计意图**：和主动1编队出击拉开档次——编队出击是补常驻舰队，全甲板攻击是额外打一波爆发，完了就走，不影响常驻舰队编成。

**实现方式**：`fleet_event` → `owner` scope，直接用 `create_fleet` + `set_timed_fleet_flag`（或通过 `country_event` + `days` 延迟自毁）：

```
create_fleet = {
    name = random
    settings = { ... }
    effect = {
        set_owner = event_target:br_void_country
        set_location = { target = event_target:br_hero_ship_@root }
        while = {
            count = root.owner.value:br_carrier_full_deck_count
            create_ship = {
                name = random
                design = event_target:br_carrier_ship_@root
            }
        }
        add_modifier = {
            modifier = br_carrier_full_deck
            mult = root.owner.value:br_carrier_full_deck_dmg
            days = 60
        }
        # 60天后自毁
        set_timed_fleet_flag = { flag = br_carrier_strike_fleet days = 60 }
    }
}
```

> 注意：临时舰队设 `owner = br_void_country`，与主舰队的归属一致。

---

### ⑥ 绝对制空 — 属性赋能

无人机舰队获得英雄舰的属性加成：

* 无人机获得英雄舰 **ship_accuracy_add** 的 **50%**
* 无人机获得英雄舰 **ship_fire_rate_mult** 的 **50%**
* 持续 **30 天**（受 `daymult` 强化）
* 冷却 **480 天**（受 `cdmult` 强化）

**设计意图**：英雄舰越强，无人机越强。让航母核心的养成与战斗能力直接挂钩。

**实现方式**：`fleet_event` → 读取英雄舰属性 → 作为 `mult` 施加 `add_modifier`：

```
event_target:br_hero_ship_@root = {
    set_variable = {
        which = br_carrier_hero_accuracy
        value = ship_accuracy_add    # 读取英雄舰命中
    }
    set_variable = {
        which = br_carrier_hero_fire_rate
        value = ship_fire_rate_mult  # 读取英雄舰射速
    }
}
event_target:br_void_country = {
    random_owned_fleet = {
        limit = { has_fleet_flag = br_carrier_fleet_@root }
        add_modifier = {
            modifier = br_carrier_hero_empower
            mult = value:br_carrier_hero_accuracy
            days = 1
            time_multiplier = root.owner.value:br_carrier_hero_empower_day
        }
        add_modifier = {
            modifier = br_carrier_hero_fire_rate
            mult = value:br_carrier_hero_fire_rate
            days = 1
            time_multiplier = root.owner.value:br_carrier_hero_empower_day
        }
    }
}
```
