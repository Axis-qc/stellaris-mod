# 自动无畏战舰 设计文档

> 自动无畏战舰（TYPE = dreadnought，原版 Automated Dreadnought）的定位与备选方向。已实装，数值与实现细节以代码为准；通用框架见 `利维坦系统.md`。

## 定位与主题

炮击型巨兽：古代文明的无人自动战舰，保留原版机械舰观感（舰体、金属炮塔、引擎尾焰）。战斗定位是火力平台——七门大型炮塔加一门泰坦激光的输出位面面板火力冠绝舰队，技能组围绕「更快的爆发」与「更硬的装甲」展开，速战速决的炮击核心。军事型定位，不配行星支援。

## 已实装指针

- 技能（槽 1/2/3）：净化齐射 / 装甲重组 / 全弹发射，实装于 `common/scripted_actions/lev_dreadnought_actions.txt` 与 `common/static_modifiers/lev_dreadnought_buffs.txt`；数值随成长等级动态，基准见 `common/script_values/lev_skill_values.txt`（lev_sk_dread_*）。
- 每级成长：`LEV_DREADNOUGHT_CORE`（`common/component_templates/lev_cores.txt`），`mult = owner.lev_dreadnought_growth_level`。
- 炮塔观感：区段槽位保留原版 large_turret / small_turret / point_defence_turret，炮塔模型由槽位模板按武器类型自动挂载——机械舰与生物舰（全 invisible_*）的处理差异；XL 槽沿用 invisible_extra_large_fixed（泰坦激光是武器特效）。原版无 attack 动画（开火表现由炮塔与武器特效承担），section entity 不写 attack 态。
- 模型链：`lev_dreadnought_mesh` 引用原版 npf_01_npc_warship_01.mesh（CLEAN 贴图版），动画注册自建 lev_dreadnought_ 前缀指向原版船体动画文件。事件 lev.230~232（`events/lev_dreadnought_events.txt`）。
- 获取：解锁法令（`common/edicts/lev_unlock_edicts.txt`，置 `lev_dreadnought_unlocked`）+ 调试折跃（`events/lev_debug_events.txt`）。

## 备选方向（未实装）

1. 全弹发射可加「敌舰武器射程降低」（弹幕遮蔽观瞄），ship_weapon_range_mult 字段已确认存在。
2. 装甲重组可升级为「战斗中缓慢修复船体」，用 ship_hull_regen_add_static 字段即可，属数值调整。
3. 未来做泰坦激光专属组件（复刻原版 200% 伤害）时 XL 槽已就位，只需新增 weapon 组件与特殊音效。
4. 可加 aura 型被动（附近友军火控加成），引擎的 ship aura 组件体系支持，但会引入组件栏位设计变更。
