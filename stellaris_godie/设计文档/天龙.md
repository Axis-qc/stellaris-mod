# 天龙（利维坦）具体方案

> 本文件是「利维坦系统」下**天龙**的具体数值 / 技能 / 实现方案（V1 实装版本）。
> 通用框架见 `利维坦系统.md`；以太巨龙的完整参考实现见 `以太巨龙.md`；克隆工程模式照抄以太巨龙。
> 数值基准：`数值设计规范.md`。

---

## 一、定位 / 主题

- 主题：深海守护。天龙是原版 Here Be Dragons / Aquatics Species Pack 的守护巨龙（`space_dragon_origin`），守护型的深海巨兽：以「潮汐压制」削弱敌舰火力，以「深渊鳞壁」强化自身防御，大招「龙啸深渊」提供全星系控场。
- 与以太巨龙的差异定位：以太巨龙偏「减益 + 自身射速」，天龙偏「控场 + 极限坦度」——大招额外带减速与闪避削减，二技能护甲倍率更高并叠加船体再生。
- 模型：原版天龙（`aquatic_dragon_01.mesh` 三段式模型），实体链全用 `lev_aquatic_*` 前缀克隆。
- DLC 门槛：Aquatics Species Pack（原版天龙来自该包的 Here Be Dragons 起始线；本期实装不挂获取线，发放由主控统一接线）。

## 二、技能组（V1 实装版本）

本期实装 3 个主动技能（槽 1/2/3）。本期不做直接伤害，效果一律以减益/增益实现。

| 槽位 | 技能 | 效果 | 冷却 | 持续 |
|---|---|---|---|---|
| 1 | 潮汐吐息 | 本星系敌舰武器伤害 -25%、射速 -15% | 180天 | 20天 |
| 2 | 深渊鳞壁 | 自身护甲 +50%（`ship_armor_mult`）、船体再生 +2%/天（`ship_hull_regen_add_perc`） | 240天 | 30天 |
| 3 | 龙啸深渊 | 本星系敌舰武器伤害 -35%、减速 30%（`ship_speed_mult`）、闪避 -15%（`ship_evasion_mult`） | 480天 | 40天 |

字段说明：`ship_armor_mult`、`ship_hull_regen_add_perc`、`ship_weapon_damage`、`ship_fire_rate_mult`、`ship_speed_mult`、`ship_evasion_mult` 均已对照原版 `common/static_modifiers` 确认存在（其中 `ship_evasion_mult`、`ship_speed_mult`、`ship_hull_regen_add_static`、`ship_shield_regen_mult`、`ship_shield_mult` 属于本期逐一验证过的字段清单）。

## 三、每级成长属性（乘以成长等级）

防御与再生方向：

| 属性 | 字段 | 每级 |
|---|---|---|
| 船体 | `ship_hull_add` | +600 |
| 护甲 | `ship_armor_add` | +700 |
| 船体再生 | `ship_hull_regen_add_perc` | +1%/天 |

成长属性由核心组件 `LEV_AQUATIC_CORE` 的 `triggered_ship_modifier`（`mult = owner.lev_aquatic_growth_level`）承载；变量读写走主控的 `lev_state_*_aquatic` scripted value（`GetLevStateLevelAquatic` 等本地化函数已在主控 `lev_growth_state_loc.txt` / `lev_growth_values.txt` 注册）。

## 五、专属机制说明

* **floater 多段模型链**：原版天龙不是单 mesh——主体 `aquatic_dragon_01.mesh`（`aquatic_dragon_01_mesh`，两个 meshsettings 段：`PdxMeshShipDiffuseEmissive` 主体 + `PdxMeshAlphaAdditive` 半透明鳍）之上，还 attach 了两个 floater 副实体（身体流光 `aquatic_dragon_floater_01.mesh` 与翼部流光 `aquatic_dragon_floater_03.mesh`，shader 均 `PdxMeshAlphaAdditiveAnimateUV`，贴图 `dragon_floater_01/02.dds` 配 `nonormal.dds`/`nospec.dds`）。mod 侧完整克隆了这条链：
  1. `lev_aquatic.gfx` 定义 3 个 pdxmesh（主体 + floater_1 + floater_2），meshsettings 逐字照抄原版 `guardian_01_space_dragon.gfx` 对应段；
  2. `lev_aquatic.asset` 先定义 `lev_aquatic_floater_1_entity` / `lev_aquatic_floater_2_entity`（含各自的 `uv_animation_speed` / `uv_animation_direction` / `bloom_factor`），再在 `lev_aquatic_section_entity` 里 `attach = { part1 = ... }` 两次挂接；
  3. floater 各自有独立动画组（idle/moving/attack/death），注册在对应 pdxmesh 的 `animation = { id = ... type = ... }` 行。
* **动画文件解析规则**：.anim 按声明处所在目录解析。原版 12 个动画（主体 4 + floater_01 4 + floater_03 4）已全部 `Copy-Item` 到 `gfx/models/ships/guardians/aquatic/` 并 Test-Path 验证；.asset 的 animation 注册块 `file` 写裸文件名，由本目录解析。原版状态机没有的动画（如 hatching）不凭空加。
* **实体镜像**：section entity 状态集（idle/moving/death/combat_moving/attack，`animation_blend_time` 与原版一致）、`game_data = { size = 50 }`、舰船 entity 的 `cull_radius` / `dissolve_on_death` / `ship_color`（hsv 0.6 1.0 0.75）全部照抄原版 `aquatic_dragon_entity` / `aquatic_dragon_section_entity`；音效（`aqu_dragon_*`）按克隆模式省略。
* **区段**：原版 `space_dragon_origin_key` 的槽位是 `medium_turret` / `point_defence_turret`（会长大炮塔），全部换成 `invisible_medium_turret_fixed` / `invisible_point_defence_turret`；locatorname（`xl_gun_01` 系）、槽位数、`aux_utility_slots = 2`、`large_utility_slots = 4` 逐字保留。
* 船体手感：`max_speed = 110`、加速 0.4、转速 0.5、碰撞半径 10，龙级快船。
* 技能无资源门槛（`possible`/`button_clickable` = `always = yes`），不引用 begin/progress/finish 动画状态。
* 事件作用域与以太巨龙同款：事件内 `THIS = from = 施放舰队`，敌舰减益经 `event_target:lev_caster` + `every_ship_in_system` 判定 `is_hostile` 施加。
* 实机验证项（主控统一接线后跑）：`lev_aquatic_growth_level` 变量接线、`is_hostile` 判定、floater attach 渲染。

## 六、备选方向

* 潮汐吐息追加「水压禁跃」：敌舰无法紧急脱离（依赖引擎 status 机制，本期未做）。
* 龙啸深渊追加「深渊恐惧」：敌方舰队强制后撤一段距离（fleet 行为队列支持后接入）。
* 深渊鳞壁后期追加「反伤鳞刺」：受击反弹固定比例伤害（需伤害事件组合，暂缓）。
