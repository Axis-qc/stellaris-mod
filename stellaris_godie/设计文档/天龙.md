# 天龙（利维坦）具体方案

> 天龙（TYPE = aquatic，原版 Aquatics 的守护巨龙）的定位、独有工程知识与备选方向。已实装，数值与实现细节以代码为准；通用框架见 `利维坦系统.md`。

## 定位 / 主题

深海守护：守护型的深海巨兽，偏「控场 + 极限坦度」——大招额外带减速与闪避削减，二技能护甲倍率更高并叠加船体再生；与以太巨龙「减益 + 自身射速」的路线区分。第 4 支援技能为冰焰庇护（行星支援，`lev_aquatic_support`，见 `common/scripted_actions/lev_support_actions.txt` 与 `events/lev_support_events.txt`）。

## 已实装指针

- 技能（槽 1/2/3）：冰焰吐息 / 守望鳞壁 / 冰焰风暴（机制为原案：削敌火力 / 自身护甲再生 / 全星系控场），实装于 `common/scripted_actions/lev_aquatic_actions.txt` 与 `common/static_modifiers/lev_aquatic_buffs.txt`；数值随成长等级动态，基准见 `common/script_values/lev_skill_values.txt`（lev_sk_aquatic_*）。
- 每级成长：`LEV_AQUATIC_CORE`（`common/component_templates/lev_cores.txt`），`mult = owner.lev_aquatic_growth_level`。
- 模型链：三段式 floater 结构（见下），专属动力 LEV_AQUATIC_REACTOR / _THRUSTER。事件 lev.260~262（`events/lev_aquatic_events.txt`）。
- 获取：解锁法令（`common/edicts/lev_unlock_edicts.txt`，置 `lev_aquatic_unlocked`）+ 调试折跃（`events/lev_debug_events.txt`）。

## 独有工程知识

- floater 多段模型链三步克隆法：原版天龙在主体 mesh 之上 attach 两个流光 floater 副实体（身体流光 + 翼部流光，PdxMeshAlphaAdditiveAnimateUV）。克隆步骤：① .gfx 定义 3 个 pdxmesh（主体 + floater_1 + floater_2），meshsettings 逐字照抄；② .asset 先定义两个 floater entity（含 uv_animation_speed / uv_animation_direction / bloom_factor），再在 section entity 里 attach 两次；③ floater 各自注册独立动画组（idle/moving/attack/death）。
- 动画文件解析规则：.anim 按声明处所在目录解析。原版 12 个动画（主体 4 + floater_01 4 + floater_03 4）已复制进 `gfx/models/ships/guardians/aquatic/`，.asset 注册块 file 写裸文件名；原版状态机没有的动画不凭空加。
- 实体镜像：状态集、game_data size、cull_radius / dissolve_on_death / ship_color（hsv 0.6 1.0 0.75）照抄原版，音效省略；区段 1 XL + 8 medium + 4 PD 全换隐形变体。
