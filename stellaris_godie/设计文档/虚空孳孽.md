# 虚空孳孽（利维坦）具体方案

> 虚空孳孽（TYPE = voidspawn，原版 Distant Stars 的虚空孳孽）的定位、独有工程知识与备选方向。已实装，数值与实现细节以代码为准；通用框架见 `利维坦系统.md`。

## 定位 / 主题

虚空虫巢：巨型缓慢的孵化母巢（70 速 / 碰撞半径 25），主打护盾穿透与削甲。与天龙/以太巨龙的差异：天龙系是敏捷龙形（快船高控场），虚空孳孽是巨型缓慢母巢，二技能是全家族唯一的静态船体再生 + 护盾组合。军事型定位，不配行星支援。

## 已实装指针

- 技能（槽 1/2/3）：黏液喷吐 / 贪食生长 / 尖刺风暴（机制为原案：压制敌盾 / 自身再生护盾 / 全星系削甲），实装于 `common/scripted_actions/lev_voidspawn_actions.txt` 与 `common/static_modifiers/lev_voidspawn_buffs.txt`；数值随成长等级动态，基准见 `common/script_values/lev_skill_values.txt`（lev_sk_voidspawn_*）。
- 每级成长：`LEV_VOIDSPAWN_CORE`（`common/component_templates/lev_cores.txt`），`mult = owner.lev_voidspawn_growth_level`。
- 模型链：`lev_voidspawn_mesh`（PdxMeshShip 主体 + AlphaBlendNoDepth_00 触须毛发表，shader 引用照原版，贴图/模型指向原版文件）。事件 lev.2000~2002（`events/lev_voidspawn_events.txt`）。
- 获取：解锁法令（`common/edicts/lev_unlock_edicts.txt`，置 `lev_voidspawn_unlocked`）+ 调试折跃（`events/lev_debug_events.txt`）。

## 独有工程知识

- 动画取舍：原版注册 4 条动画（idle/moving/hatching/death），hatching 属原版 ambient object 孵化演出流程，玩家舰实体无该状态，不引用；玩家舰只保留 idle/moving/death 三条。
- 实体镜像：原版状态机是「双 idle / 双 moving 交替 chance 播放」结构，克隆保留状态骨架（looping = no next_state 自续），音效省略；死亡粒子 distant_stars_gib_explosion_effect 照抄。单段模型，无 attach。
- 区段：原版 voidspawn_key 的 3 鱼雷 + 3 medium 全换隐形变体（invisible_missile_turret 保持鱼雷槽语义 / invisible_medium_turret_fixed），locatorname、aux 2、large 10 逐字保留；section_slots 用原版 `spine` locator（天龙系是 part1）。
