# 舰队行为队列 (queue_actions)

> 适用版本：Stellaris 4.x | 最后更新：2026-06-27

## 概述

`queue_actions` 是舰队作用域下的效果，用于给舰队编排自动化行为序列。舰队会按顺序执行队列中的动作，支持循环、条件分支、搜索等复杂逻辑。

### 基本语法

```hcl
# 设置行为队列
queue_actions = {
    # 动作序列...
}

# 清除行为队列
clear_fleet_actions = this
```

### 关键规则

- 所有带 `trigger` 的搜索动作需要唯一 `id` 字段（用于存档兼容）
- `id` 命名建议：`"{事件ID}.{用途}@{作用域}"`，如 `"br.830.trigger.1@root"`
- 动作在队列中按顺序执行，`repeat` 内的动作循环执行
- 队列可嵌套：搜索动作的成功/失败块内可继续编排子动作

## 动作清单

### 移动类

| 动作 | 语法 | 说明 |
|------|------|------|
| `move_to` | `move_to = scope` | 移动到目标星系/行星/舰队 |
| `orbit_planet` | `orbit_planet = scope` | 环绕行星轨道运行 |

### 等待类

| 动作 | 语法 | 说明 |
|------|------|------|
| `wait` | `wait = { duration = N random = M }` | 等待 N±M 天 |
| `wait` | `wait = N` | 等待固定 N 天（旧语法） |

### 效果类

| 动作 | 语法 | 说明 |
|------|------|------|
| `effect` | `effect = { id = "unique_id" ... }` | 执行任意效果，必须提供唯一 id |

### 循环类

| 动作 | 语法 | 说明 |
|------|------|------|
| `repeat` | `repeat = { while = {...} max_iterations = N ... }` | 循环执行子动作 |

- `while`：AND 触发器，条件不满足时停止循环（需要唯一 id）
- `max_iterations`：最大迭代次数，达到后停止
- 两者可选，都不写则无限循环

### 搜索类

所有搜索动作共享相同的结构模式：

```hcl
find_xxx = {
    trigger = {           # 可选，过滤条件（需要 id）
        id = "unique_id"
        ...
    }
    found_xxx = {         # 找到时执行
        # 子动作...
    }
    failed = {            # 可选，未找到时执行
        # 子动作...
    }
}
```

| 动作 | 搜索范围 | 成功块 | 说明 |
|------|---------|--------|------|
| `find_closest_planet` | 当前星系 | `found_planet` | 最近行星 |
| `find_random_planet` | 当前星系 | `found_planet` | 随机行星，可不写 trigger |
| `find_closest_system` | 全图 | `found_system` | 最近星系 |
| `find_random_system` | 全图 | `found_system` | 随机星系，支持 distance 范围 |
| `find_closest_fleet` | 全图 | `found_fleet` | 最近舰队 |
| `find_random_fleet` | 全图 | `found_fleet` | 随机舰队 |

### 特殊类

| 动作 | 语法 | 说明 |
|------|------|------|
| `terraform_fleet` | `terraform_fleet = scope` | 舰队改造行星（Infernals 危机专用） |

## 舰队级独立效果

除了 `queue_actions` 内的编排动作，舰队作用域下还有一批**直接生效的独立效果**，用于控制舰队的自动行为、战斗姿态、阵型等。

### 自动移动

| 效果 | 语法 | 说明 |
|------|------|------|
| `auto_follow_fleet` | `auto_follow_fleet = { target = scope attack_fleet = yes }` | 持续追踪并攻击目标舰队 |
| `auto_move_to_planet` | `auto_move_to_planet = { target = scope clear_auto_move_on_arrival = no }` | 自动移动到行星 |

`auto_move_to_planet` 参数：

| 参数 | 值 | 说明 |
|------|----|------|
| `target` | 行星作用域 | 目标行星 |
| `clear_auto_move_on_arrival` | `yes` / `no` | `no` 时被打断会重新飞回目标 |
| `destroy_on_arrival` | `yes` | 到达后自毁（可选） |

### 战斗姿态

| 效果 | 可选值 | 说明 |
|------|--------|------|
| `set_fleet_stance` | `aggressive` / `passive` / `evasive` | 舰队交战姿态 |
| `set_fleet_bombardment_stance` | `indiscriminate` / `armageddon` / `behemoth_invasion` | 轨道轰炸姿态 |
| `set_aggro_range` | 数值（距离） | 仇恨范围 |
| `set_aggro_range_measure_from` | `self` / `return_point` | 仇恨测量基准点 |

`set_aggro_range_measure_from` 说明：
- `self`：以舰队自身当前位置为基准计算仇恨范围
- `return_point`：以舰队的生成点/返回点为基准，舰队远离后仍会回到该区域

### 阵型

| 效果 | 语法 | 说明 |
|------|------|------|
| `set_fleet_formation` | `set_fleet_formation = { position = { x = N y = N } ... }` | 自定义舰船排列坐标 |
| `set_formation_scale` | `set_formation_scale = N` | 阵型缩放系数 |

```hcl
# 示例：9艘船的菱形阵型
set_fleet_formation = {
    position = { x = 14.0  y = -3.0  }  #9
    position = { x = 1.3   y = -11.0 }  #8
    position = { x = -10.5 y = 1.0   }  #7
    position = { x = 3.0   y = 8.0   }  #6
    position = { x = -4.3  y = -7.0  }  #5
    position = { x = 8.0   y = 9.0   }  #4
    position = { x = -4.0  y = 7.3   }  #3
    position = { x = 7.5   y = -10.5 }  #2
    position = { x = 0.0   y = 0.0   }  #1
}
set_formation_scale = 0.5
```

### 标记与队列控制

| 效果 | 语法 | 说明 |
|------|------|------|
| `set_fleet_flag` | `set_fleet_flag = xxx` | 打标记 |
| `remove_fleet_flag` | `remove_fleet_flag = xxx` | 移除标记 |
| `clear_fleet_actions` | `clear_fleet_actions = this` | 清空行为队列 |

### 常用组合套路

**哨兵模式**：舰队在目标行星巡逻，被打跑后自动返回
```hcl
set_fleet_stance = aggressive
set_aggro_range = 200
set_aggro_range_measure_from = return_point
auto_move_to_planet = {
    target = event_target:guard_planet
    clear_auto_move_on_arrival = no
}
```

**自杀式攻击**：舰队直奔目标，到达后自毁
```hcl
set_fleet_stance = aggressive
auto_move_to_planet = {
    target = event_target:target_planet
    destroy_on_arrival = yes
    clear_auto_move_on_arrival = yes
}
```

**追击猎杀**：舰队持续追踪并攻击目标舰队
```hcl
set_fleet_stance = aggressive
auto_follow_fleet = {
    target = event_target:enemy_fleet
    attack_fleet = yes
}
```

## 实用模式

### 1. 巡逻漫游

```hcl
queue_actions = {
    repeat = {
        find_random_system = {
            trigger = {
                id = "patrol.1@root"
                distance = {
                    source = root.owner.capital_scope.star
                    max_distance <= 300
                    min_distance >= 50
                }
            }
            found_system = {
                move_to = this
                find_random_planet = {
                    found_planet = {
                        orbit_planet = this
                        wait = { duration = 60 random = 30 }
                    }
                }
            }
        }
    }
}
```

### 2. 追击目标舰队

```hcl
queue_actions = {
    repeat = {
        find_closest_fleet = {
            trigger = {
                id = "hunt.1@root"
                owner = { has_country_flag = enemy_flag }
            }
            found_fleet = {
                move_to = this
            }
        }
    }
}
```

### 3. 条件终止循环

```hcl
queue_actions = {
    repeat = {
        while = {
            id = "loop_check@root"
            has_hp_percentage > 0.3
        }
        max_iterations = 20
        find_closest_system = {
            trigger = {
                id = "target.1@root"
                has_star_flag = mission_target
            }
            found_system = {
                move_to = this
                find_closest_planet = {
                    trigger = { id = "target.2@root" is_star = yes }
                    found_planet = {
                        move_to = this
                        orbit_planet = this
                        effect = {
                            id = "arrival@root"
                            root = { clear_fleet_actions = this }
                        }
                    }
                }
            }
            failed = {
                effect = {
                    id = "no_target@root"
                    root = { remove_fleet_flag = on_mission }
                }
            }
        }
    }
}
```

### 4. 到达后触发事件

```hcl
queue_actions = {
    move_to = event_target:destination
    wait = { duration = 5 }
    effect = {
        id = "arrival_trigger@root"
        root.owner = { country_event = { id = br.999 } }
    }
}
```

### 5. 单次搜索后停止

```hcl
queue_actions = {
    repeat = {
        max_iterations = 1
        find_closest_planet = {
            trigger = {
                id = "find_home@root"
                is_capital = yes
            }
            found_planet = {
                move_to = this
                orbit_planet = this
            }
        }
    }
}
```

## 本 mod 中的实际应用

### PVE 突击舰队追踪（br_pve_reinforce_events.txt）

```hcl
# br.830 — 年度重新绑定追踪
auto_follow_fleet = {
    target = event_target:br_dominator_fleet_@root
    attack_fleet = yes
}

# br.840 — 新刷舰队直接跟随攻击
auto_follow_fleet = {
    target = event_target:br_dominator_fleet_@root
    attack_fleet = yes
}
```

`auto_follow_fleet` 是独立于 `queue_actions` 的舰队效果，直接让舰队持续跟随并攻击目标，无需写入队列。

---

## 三种行为控制方式对比

| 特性 | queue_actions | auto_follow_fleet | auto_move_to_planet |
|------|--------------|-------------------|---------------------|
| 实时追踪 | 需 repeat + find 循环 | 自动持续追踪 | 被打断会重新飞回 |
| 攻击目标 | 需额外编排 | `attack_fleet = yes` | 仅移动不攻击 |
| 目标类型 | 任意作用域 | 舰队 | 行星 |
| 灵活性 | 可编排复杂行为链 | 仅跟随+攻击 | 仅移动+自毁 |
| 适用场景 | 巡逻、探索、多阶段任务 | 追击、猎杀 | 哨兵、自杀攻击 |

---

## 注意事项

- `find_random_planet` 不写 `trigger` 时匹配任意行星，适合纯随机巡逻
- `find_random_system` 的 `distance` 支持 `type = hyperlane` 按超空间跳数计算
- `effect` 的 `id` 在同一舰队的所有队列中必须全局唯一
- `clear_fleet_actions = this` 会清空队列，舰队恢复空闲状态
- 搜索动作的 `found_xxx` 块内 `this` 指向找到的目标作用域
