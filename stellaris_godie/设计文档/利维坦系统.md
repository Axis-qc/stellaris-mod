# 利维坦系统（Leviathan System）

复用原版利维坦模型做玩家可拥有的利维坦舰。11 只利维坦（噬星者/以太巨龙/巨龙/幽魂/位面之魇/毒圣/自动无畏战舰/拾荒机器人/虚空孳孽/天龙/无限神机）已全部实装，含成长值系统、技能组数值等级化、行星支援系统。

利维坦不可在星港建造，也不可合并、解散、变更编队与更换指挥官，只允许升级；不占海军容量。唯一获取途径是解锁法令发放，被摧毁后每年年初自动补发。

本档只留系统总览与扩展入口，实装细节查各只方案文档与代码。

- 数值设计规范.md：英雄舰（先锋级）数值基准；利维坦的技能数值与成长曲线以 `common/script_values/lev_skill_values.txt`、`lev_growth_effects.txt` 实装为准，该规范不约束利维坦（其 §10.1 天花板对利维坦有例外条款）

## 新增一只利维坦要动哪四处

1. `common/scripted_triggers/lev_leviathan_triggers.txt` —— `lev_is_leviathan_ship` 的 OR 加一行 `is_ship_size`；支援型利维坦另在 `lev_has_support_leviathan` 加一行
2. `common/scripted_effects/lev_growth_effects.txt` —— `lev.20` 加一个 if 分支（判定哪只在击杀星系内，给谁入账）；`lev_feed_settle_all` 加一行 `lev_feed_settle = { TYPE = <新TYPE> }`
3. `common/button_effects/lev_ui_buttons.txt` + `interface/br_level_view.gui` —— UI 卡片槽与营养档位按钮
4. `events/lev_revive_events.txt` —— `lev.330` 里加一行 `lev_revive_one = { TYPE = <小写后缀> NAME = LEV_<大写后缀>_FLEET }`（发放交给 `lev_grant_effects.txt` 的 `lev_grant_one`，舰队名取本地化键 `$NAME$`）
5. 舰种/区段/技能事件/本地化等新建文件，参考既有 `lev_<TYPE>_*.txt` 同构照抄

命名空间 `lev_*`，与先锋级英雄舰（`br_hero_*`）是独立系统；技能倍率沿用 `br_hero_ship_skill_{1/2/3}_mult` 约定。
