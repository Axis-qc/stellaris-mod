# 拾荒机器人（利维坦）

> 拾荒机器人（TYPE = scavenger，原版 Scavenger Bot）的定位与备选方向。已实装，数值与实现细节以代码为准；通用框架见 `利维坦系统.md`。

## 定位主题

古代文明遗留的自动化拆解巨构，主题为「回收拼装」：一切战斗收益都来自对战场残骸的拆解、熔铸与再利用。舰体巨大笨重，以超厚护甲承受伤害，再以技能把受损装甲重组如新；输出依赖导弹阵列与巨型主炮。

## 已实装指针

- 技能（槽 1/2/3）：碎甲重组 / 焊接强化 / 掠夺协议，实装于 `common/scripted_actions/lev_scavenger_actions.txt` 与 `common/static_modifiers/lev_scavenger_buffs.txt`；数值随成长等级动态，基准见 `common/script_values/lev_skill_values.txt`（lev_sk_scav_*）。
- 每级成长：`LEV_SCAVENGER_CORE`（`common/component_templates/lev_cores.txt`），`mult = owner.lev_scavenger_growth_level`。
- 第 4 支援技能：废料回收网（行星支援，`lev_scavenger_support`，见 `common/scripted_actions/lev_support_actions.txt` 与 `events/lev_support_events.txt`）。
- 双 mesh 结构：外框（frame）+ 核心（core），舰船实体挂外框、区段实体挂核心，get_state_from_parent 跟随主实体状态；专属动力 LEV_SCAVENGER_REACTOR / _THRUSTER（`lev_reactors.txt` / `lev_thrusters.txt`）。事件 lev.1700~1702（`events/lev_scavenger_events.txt`）。
- 获取：解锁法令（`common/edicts/lev_unlock_edicts.txt`，置 `lev_scavenger_unlocked`）+ 调试折跃（`events/lev_debug_events.txt`）。

## DLC 门槛

原版拾荒机器人随 Distant Stars Story Pack 发布，系统生成门槛为 `has_distar`（内部即 `host_has_dlc = "Distant Stars Story Pack"`）。获取线接入时按此门槛校验。
