# 虚境探索系统 — 设计文档

> **⚠ 纯设计文档，尚未实现。**

> 虚空挑战模式中的虚境探索子系统。
> 独立于中途事件，有自己的事件链和奖励体系。
> 不依赖原版虚境事件，所有奖励针对mod环境设计。

---

## 系统概述

虚境探索是虚空挑战模式中的特殊成长路径。玩家在推进过程中随机遇到虚境相关现象，通过战斗或调查获得探索虚境的机会，按英雄等级获取不同档次的奖励，极稀有情况下可与超主建立契约获得永久力量。

```
进入新星系 ─┬─ 6% → 虚境回响（event.shroud.1）调查/净化
            ├─ 4% → 虚境实体舰队（event.shroud.2）击败 → 探索
            └─ 2% → 虚境传送门（event.shroud.3）进入 → 探索等级+1
                         │
                         ▼
               虚境探索（event.shroud.10）
               ┌──────────────────────┐
               │ 按英雄等级加权分配奖励等级 │
               ├──────────────────────┤
               │ 低级: buff/资源/回血     │
               │ 中级: 灵能作战电脑/护盾   │
               │ 高级: 灵能跃迁引擎/轰炸   │
               │ 稀有: → 超主契约         │
               └──────────────────────┘
                         │
                         ▼
               超主契约（event.shroud.20）
               ┌──────────────────────┐
               │ 世界之喰煞: 伤害+射速  │
               │ 生命之织缕: 三维      │
               │ 渴求之器具: 资源      │
               │ 虚空之低语: 研究      │
               │ (各有代价 + 主动协议)  │
               └──────────────────────┘
```

## 事件链

### event.shroud.1 — 虚境回响

**触发**：进入新星系时 6% 概率触发（灵能印记 ≥ 1 时概率翻倍）

**描述**：星系中出现了虚境能量的异常波动，空气中弥漫着超自然的气息。

**选项**：

| 选项 | 效果 |
|------|------|
| A. 调查异常 | 消耗 200 合金，获得 1 层灵能印记 + 150 XP。10% 概率触发 event.shroud.10 虚境探索 |
| B. 净化能量 | 消除 1 层灵能印记 + 获得 300 合金 |
| C. 忽略 | 无效果 |

**实现**：`on_entering_system` 钩子 + `random_list` 概率触发。不刷实体舰队，纯事件选择

---

### event.shroud.2 — 虚境实体舰队

**触发**：进入新星系时 4% 概率触发（灵能印记 ≥ 2 时概率翻倍）

**描述**：星系中出现了一支由虚境能量凝聚而成的实体舰队，散发着诡异的光芒。

**效果**：
- 刷出 3-5 艘虚境实体敌舰（使用原版 `psionic_avatar` 设计模板，通过 modifier 调整属性适配当前区域难度）
- 击败后 100% 触发 event.shroud.10 虚境探索
- 击败奖励：200 XP + 1 层灵能印记 + 100 sr_zro

**实现**：`on_entering_system` + `create_fleet` 生成虚境实体舰队。实体舰船使用 `ship_size = psionic_avatar` 模板。击杀后触发探索事件

---

### event.shroud.3 — 虚境传送门

**触发**：进入新星系时 2% 概率触发（灵能印记 ≥ 3 时概率 ×3）

**描述**：星系中出现了一道通往虚境的传送门，门后是未知的世界。

**选项**：

| 选项 | 效果 |
|------|------|
| A. 进入传送门 | 触发 event.shroud.10 虚境探索（奖励等级自动提升一档） |
| B. 封印传送门 | 获得 1 层灵能印记 + 500 合金 + 200 XP |
| C. 吸收能量 | 英雄舰获得 300 XP，50% 概率获得 1 层灵能印记 |

---

### event.shroud.10 — 虚境探索（核心事件）

**触发**：击败虚境实体舰队（event.shroud.2）/ 调查虚境异常（event.shroud.1 10%概率）/ 进入虚境传送门（event.shroud.3）后触发

**描述**：你的灵能感知深入虚境，发现了其中隐藏的力量……

**奖励等级由英雄等级决定**（`random_list` 加权）：

| 英雄等级 | 低级权重 | 中级权重 | 高级权重 | 稀有权重 |
|:------:|-------:|-------:|-------:|-------:|
| 1-3 | 80 | 20 | 0 | 0 |
| 4-6 | 50 | 40 | 10 | 0 |
| 7-9 | 20 | 50 | 28 | 2 |
| 10-12 | 10 | 30 | 55 | 5 |
| 13+ | 5 | 20 | 65 | 10 |

> 虚境传送门入口（event.shroud.3）自动将奖励等级提升一档（低→中，中→高，高→稀有）。

#### 低级奖励（随机1项）

| 奖励 | 效果 |
|------|------|
| 虚境护佑 | 英雄舰三维各 +10%（60天） |
| 虚境馈赠 | 400 合金 + 100 XP |
| 灵能感知 | 命中 +10，追踪 +10（60天） |
| 虚境回血 | 英雄舰回复 30% 船体/护甲/护盾 |

#### 中级奖励（随机1项）

| 奖励 | 效果 | 解锁条件 |
|------|------|---------|
| 灵能作战电脑 | 英雄舰获得灵能作战电脑组件（命中 +15，追踪 +15，闪避 +10） | 英雄舰等级 ≥ 5 |
| 灵能护盾技术 | 英雄舰获得灵能护盾组件（护盾值 +50%） | 英雄舰等级 ≥ 5 |
| 虚境武器强化 | 武器伤害永久 +8% | 无 |
| 高级碎片 ×2 | 获得 2 个随机类型的高级碎片 | 无 |

#### 高级奖励（随机1项）

| 奖励 | 效果 | 解锁条件 |
|------|------|---------|
| 灵能跃迁引擎 | 英雄舰获得灵能跃迁引擎组件（速度 +40%，闪避 +15） | 英雄舰等级 ≥ 8 |
| 灵能轰炸技术 | 英雄舰获得灵能轰炸组件（轨道轰炸 +50%） | 英雄舰等级 ≥ 8 |
| 虚境武器精通 | 武器伤害永久 +15% + 射速永久 +10% | 无 |
| 虚境结构 | 船体/护甲/护盾永久各 +20% | 无 |

#### 稀有奖励 → 触发 event.shroud.20 超主契约

概率由灵能印记层数 + 英雄等级加权决定。需灵能印记 ≥ 3 且英雄等级 ≥ 7。

---

### event.shroud.20 — 超主契约（稀有事件）

**触发**：虚境探索 event.shroud.10 稀有结果触发

**描述**：虚境深处，某个超主向你伸出了手。你感受到了无与伦比的力量，但也察觉到了代价的气息……

**选项**：

| 选项 | 效果 | 代价 |
|------|------|------|
| A. 与世界之喰煞签约 | 武器伤害永久 +20% + 射速永久 +15% + 主动协议「狂狩」 | 幸福度永久 -5%，星球稳定度永久 -5 |
| B. 与生命之织缕签约 | 船体/护甲/护盾永久各 +15% + 主动协议「变化」 | 英雄舰武器伤害永久 -5% |
| C. 与渴求之器具签约 | 资源产出永久 +20% + 主动协议「进步」 | 人口维护费永久 +25% |
| D. 与虚空之低语签约 | 研究速度永久 +25% + 主动协议「先见」 | 统一度生产永久 -15% |
| E. 拒绝签约 | 获得 1000 合金 + 500 XP + 2 层灵能印记 | 无 |

**主动协议详情**：

| 超主 | 协议名 | 激活消耗 | 效果 | 冷却 |
|------|--------|---------|------|------|
| 世界之喰煞 | 狂狩 | 100 合金 | 舰队射速 +20%，30天 | 180天 |
| 生命之织缕 | 变化 | 100 合金 | 英雄舰三维 +30%，30天 | 180天 |
| 渴求之器具 | 进步 | 100 合金 | 全系统友军伤害 +15%，30天 | 180天 |
| 虚空之低语 | 先见 | 100 合金 | 所有技能冷却 -30 天 | 180天 |

**实现**：
- 契约效果通过永久 modifier 施加
- 主动协议通过 `scripted_action` 按钮实现，消耗资源触发 `country_event` 施加临时 modifier
- 每个玩家只能签一次契约（flag `br_has_covenant` 门控）
- 签约后解锁对应超主的主动协议按钮（在英雄舰UI面板）

## 灵能组件一览

虚境探索可获取的灵能舰船组件：

| 组件 | 类型 | 效果 | 获取方式 |
|------|------|------|---------|
| 灵能作战电脑 | 电脑 | 命中 +15，追踪 +15，闪避 +10 | 中级奖励 |
| 灵能护盾 | 护盾 | 护盾值 +50% | 中级奖励 |
| 灵能跃迁引擎 | 引擎 | 速度 +40%，闪避 +15 | 高级奖励 |
| 灵能轰炸 | 辅助 | 轨道轰炸 +50% | 高级奖励 |

> 组件需在母舰中建造后安装到英雄舰。每个组件类型只能安装1个。

## 与印记系统的互动

| 印记层数 | 效果 |
|:------:|------|
| ≥ 1 | 虚境回响触发概率翻倍 |
| ≥ 2 | 虚境实体舰队触发概率翻倍 |
| ≥ 3 | 虚境传送门触发概率 ×3，解锁超主契约资格 |
| 每层 | 虚境探索稀有权重 +2% |
