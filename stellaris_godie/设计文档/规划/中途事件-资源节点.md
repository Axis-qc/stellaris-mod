# 中途事件 — 资源节点

> **⚠ 纯设计文档，尚未实现。** 碎片系统、虚空印记系统、精英词条等均为设计规划。

> 达到资源或战力阈值时触发。
> 事件丰富局内体验，提供风险/收益选择，推动流派构筑。

---

### event.3401 — 战力里程碑

**触发**：玩家 power_level 提升时 100% 触发

**描述**：你的实力达到了新的高度。

**效果**（按 power_level 分档）：

| 等级 | 奖励 |
|:---:|------|
| 2 | 300 合金 + 1 个武器模块碎片 |
| 3 | 500 合金 + 1 个舰船模块碎片 + 1 个全局buff碎片 |
| 4 | 800 合金 + 1 个高级碎片 + 英雄舰 XP ×1.5（30天） |
| 5 | 1200 合金 + 2 个高级碎片 + 1 层随机印记 |

---

### event.3402 — 击杀里程碑

**触发**：累计击杀数达到 50/100/200/500 时触发

**描述**：你的战斗经验引起了虚空的注意。

**效果**：

| 击杀数 | 奖励 |
|:-----:|------|
| 50 | 英雄舰获得 300 XP + 1 层战痕印记 |
| 100 | 英雄舰获得 500 XP + 1 个高级碎片 |
| 200 | 英雄舰获得 800 XP + 所有技能 CD -60 天 |
| 500 | 英雄舰获得 1500 XP + 1 层毁灭印记 + 武器伤害永久 +10% |

---

### event.3403 — 资源积累奖励

**触发**：合金首次超过 3000/5000/10000 时触发

**描述**：你的资源储备引起了各方势力的注意。

**效果**：

| 资源阈值 | 效果 |
|:-------:|------|
| 3000 | 解锁"资源兑换"功能：可消耗 1000 资源兑换 1 个随机碎片 |
| 5000 | 解锁"雇佣兵"功能：可消耗 2000 资源雇佣 1 支临时舰队（60天） |
| 10000 | 解锁"黑市交易"：可消耗 5000 资源购买 1 个指定类型的高级碎片 |

---

### event.3404 — 碎片合成

**触发**：拥有同类型碎片 ≥ 3 个时，手动触发（通过母舰按钮）

**描述**：将多个同类型碎片合成为高级模块。

**效果**：
- 消耗 3 个同类型普通碎片 → 获得 1 个该类型的高级碎片
- 高级碎片效果 = 普通碎片 × 2.5
