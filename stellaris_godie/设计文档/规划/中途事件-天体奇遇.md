# 中途事件 — 天体奇遇

> **⚠ 纯设计文档，尚未实现。** 碎片系统、虚空印记系统等均为设计规划。

> 进入星系时检测周边天体，刷 special project 触发探索类事件。
> 基于 mod 实际系统：探索(`reward.7001`→`reward.7002`→special project→完成事件)、印记体系。

---

沿用 mod 已有的探索流程：`on_entering_system` → `reward.7001` → `reward.7002` 随机路由器 → 检测周边天体 → 刷 special project → 研究完成 → 转完成事件。与 `reward.7002` 中的遗迹挖掘、宝箱探索并列，作为新分支加入 `random_list` 权重。

### event.3501 — 远古巨构残骸

**触发**：进入星系时，`reward.7002` 检测周边星系存在巨构标记（星系生成时按概率打 `br_dyson_ruin` / `br_ringworld_ruin` 等 flag），刷出 special project。

**流程**：

`
reward.7002 random_list
  → 遍历周边星系，检测 has_star_flag = br_dyson_ruin / br_ringworld_ruin
  → 命中时以权重刷出 special project（耗时 120 天）
  → 研究完成 → event.3501
`

**描述**：扫描发现附近星系中存在一座远古巨构的残骸结构，可以派遣科考船前往研究。

**special project 阶段**：派遣科考船前往目标星系，研究耗时 120 天。

**完成事件（研究后弹出）**：

| 选项 | 效果 |
|------|------|
| A. 拆解残骸 | 获得 2 个舰船模块碎片 + 1 层科技印记 |
| B. 修复运作 | 消耗 1500 合金，该星系变为永久资源点（每 30 天 +500 合金） |
| C. 提取技术 | 获得 500 XP + 1 层古老印记 |

**标记生成**：扩圈阶段按概率为星系打 flag — `br_dyson_ruin`（15%）/ `br_ringworld_ruin`（10%）/ 其他巨构类型。

### event.3502 — 特殊行星地质研究

**触发**：进入星系时，`reward.7002` 检测当前星系或周边星系存在特殊行星类型（按 `is_planet_class` 判断），刷出 special project。

**流程**：

`
reward.7002 random_list
  → 遍历周边星系行星，检测 planet_class
  → 命中时以权重刷出 special project（耗时 90 天）
  → 研究完成 → event.3502（按行星类型分流）
`

**描述**：侦测到附近行星具有异常地质结构，派遣科考队深入研究可能发现有价值的数据。

**special project 阶段**：派遣科考船前往目标行星，研究耗时 90 天。

**完成事件（研究后弹出，按行星类型分流）**：

**盖亚世界 `pc_gaia` / 丛林 `pc_tropical` / 海洋 `pc_ocean`**：

| 选项 | 效果 |
|------|------|
| A. 研究生态样本 | 获得 1 层科技印记 + 300 XP |
| B. 提取生命能量 | 英雄舰船体/护甲/护盾各回复 30% |

**蜂巢世界 `pc_hive` / 机械星球 `pc_machine`**：

| 选项 | 效果 |
|------|------|
| A. 逆向工程 | 获得 1 个高级碎片 + 1 层科技印记 |
| B. 提取核心组件 | 获得 600 合金 + 200 XP |

**死寂星球 `pc_nuked` / 灰蛊 `pc_gray_goo` / 破碎星球 `pc_shattered`**：

| 选项 | 效果 |
|------|------|
| A. 搜索残余资源 | 获得 400 合金 + 1 层毁灭印记 |
| B. 研究毁灭痕迹 | 获得 1 层古老印记 + 200 XP |

**行星类型分布**：扩圈阶段按圈层强度分布不同行星类型，越靠近中心特殊类型越多。检测条件：遍历星系内行星 `is_planet_class`。
