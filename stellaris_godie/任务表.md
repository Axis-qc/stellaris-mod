# 奖励系统完全重置 — 工作任务

> 基于 2026-04-29 审查的现有奖励系统，按六池独立体系重建。
> 本轮只迁移已有奖励到新奖励系统，不新增奖励内容；科技池抽空后的计数/兜底机制后续再补充。

---

## 设计决策

| 决策项 | 方案 |
|--------|------|
| 等级划分 | 五级制: Lv1-2(T1) / Lv3-5(T2) / Lv6-8(T3) / Lv9-11(T4) / Lv12(T5) |
| 总触发器权重 | 资源20% / 科技25% / BUFF25% / 舰船15% / 领袖15% |
| 事件编号 | 奖励系统统一使用 `namespace = reward`，事件ID格式为 `reward.xx` |
| 编号区间 | 每个池子独占1000编号区间，例如第一个池子 `reward.1`-`reward.999`，第二个池子 `reward.1001`-`reward.1999` |
| 旧系统处理 | 不兼容旧奖励系统；能改造的改造成新系统，不能改造的直接删除 |
| 文件命名 | 新奖励系统文件统一使用 `reward_` 前缀；旧 `br_reward_*` 文件只作为迁移来源，迁移完成后删除 |
| 本轮范围 | 只迁移已有奖励；不新增Boss遗物、英雄舰强化、隐藏奖励、额外舰船或额外科技 |
| 普通/高级池 | 不再按“普通池/高级池”拆分，全部按新奖励池体系抽取，只看等级 |
| 升级奖励 | 升级不触发随机奖励；只给固定舰船科技，并保留未来“选择英雄舰”入口 |
| 流派系统 | 旧流派选择后续改为英雄舰选择；相关 flag 后续改为英雄舰/专精 flag |
| 流派检查 | 由总触发器和分池触发器检查，不在具体奖励事件里散落判断 |
| 特殊池 | 先只做空壳入口和占位文件，不填具体奖励内容 |
| 本地化 | 新建奖励系统专用本地化文件，旧奖励键迁移进去，不继续堆在旧文件 |
| 奖励展示 | 所有奖励都是弹窗自选，不做纯隐藏随机发放 |

## 硬性规则：触发权限

```
允许的调用路径：
  战斗/爆星 → 普通奖励入口 → 总触发器 → 池入口 → 池内部等级触发器 → 具体奖励弹窗
  升级     → 升级入口 → 固定舰船科技 + 未来英雄舰选择入口
  特殊事件/Boss → 特殊池入口（本轮空壳，不发放具体奖励）

禁止的调用路径：
  ✗ 战斗/爆星/普通事件直接调用池子事件
  ✗ 战斗/爆星/普通事件绕过总触发器直接调池入口
  ✗ 非特殊池入口被总触发器以外的任何事件调用
  ✗ 升级入口调用总触发器或随机奖励池
  ✗ 具体奖励事件写等级判断
  ✗ 新奖励系统调用旧 br.* 奖励事件

例外：
  ✓ 特殊池入口允许由 Boss/隐藏事件显式调用
  ✓ 固定科技推进仅由升级入口调用
  ✓ 未来英雄舰选择入口仅由升级入口调用
```

## 检测边界

- 等级检测只允许写在池入口或池内部等级触发器中。
- 流派/英雄舰/专精 flag 检测只允许写在总触发器或分池触发器中。
- 具体奖励事件不写等级检测，不写池权重逻辑，只负责展示可选项并发放奖励。
- 具体奖励允许保留“显示检测”，例如：
  - 科技已拥有时，该科技选项不显示。
  - 舰船奖励需要有可刷舰队落点时才显示对应选项。
  - 资源不足的兑换型奖励不显示对应选项。
  - 事件目标不存在时不显示依赖该目标的选项。
- 科技池可能被抽空，需要预留后续“池可用性检测/抽取计数/兜底重抽”机制；本轮先完成池子结构和显示检测。

```
战斗/爆星
  → reward.1(总触发器)
      ├─ 20% 资源池入口  reward.1001  — reward_pool_resource_events.txt
      ├─ 25% 科技池入口  reward.2001  — reward_pool_tech_events.txt
      │     └─ 每级3个分类子事件: 武器 / 防护 / 辅助(A槽)
      ├─ 25% BUFF池入口  reward.3001  — reward_pool_buff_events.txt（不分等级）
      ├─ 15% 舰船池入口  reward.4001  — reward_pool_ship_events.txt
      └─ 15% 领袖池入口  reward.5001  — reward_pool_leader_events.txt

升级（br_level_events.txt 负责，奖励系统只读变量）
  → br.6130 → br.6135(固定舰船科技推进) + 未来英雄舰选择入口
  → 升级不触发随机奖励池

特殊事件/Boss
  → 特殊池入口 reward.6001 — reward_pool_special_events.txt（本轮空壳）
```
