# 群星：虚空挑战 — Boss设计草案

> 借用原版利维坦模型，被虚空能量侵蚀后作为PVE模式的最终Boss
> Boss非开局固定，而是游戏进程中根据玩家行为和事件积累的flag动态决定

---

## 设计思路

Boss不在开局时随机选好，而是**在游戏进程中逐步积累flag，缩圈到最终阶段时根据flag池动态决定出场Boss**。

玩家在推进过程中的各种行为都会为"虚空印记"投票：

- 用什么船型打得多 → 倾向特定Boss
- 爆了多少星球 → 解锁某些狂暴系Boss
- 死了多少船 → 触发某些吞噬系Boss
- 特殊事件选择 → 解锁隐藏Boss通道

最终阶段（缩圈至最后一圈或达到某个power_level门槛）触发Boss降临事件，根据已有flag加权随机选择一个Boss。这样可以做到：

1. **每局Boss与玩家行为相关**，不是纯随机
2. **隐藏Boss需要特定条件**，增加重复可玩性
3. **后期生成**，避免开局就定死的枯燥感

## 虚空印记（Flags）分类

| 印记类型 | flag前缀                  | 来源           | 影响Boss倾向         |
|------|-------------------------|--------------|------------------|
| 战痕印记 | `br_mark_combat_*`      | 大量战斗/击杀      | 无畏战舰、远古堡垒等强战Boss |
| 毁灭印记 | `br_mark_destruction_*` | 爆星次数         | 噬星者、虚空孳孽等毁灭系     |
| 献祭印记 | `br_mark_sacrifice_*`   | 损失大量舰船       | 位面之魇、幽魂等灵异系      |
| 灵能印记 | `br_mark_psionic_*`     | 灵能相关事件       | 虚境化身、恶堕化身、虚境显圣   |
| 古老印记 | `br_mark_ancient_*`     | 探索/存活时间长     | 以太巨龙、天龙、巨龙等远古系   |
| 科技印记 | `br_mark_tech_*`        | 高power_level | 无限神机等科技系         |
| 污秽印记 | `br_mark_toxic_*`       | 毒物相关         | 毒圣、剧毒的半神         |

## Boss选择逻辑

```
Boss降临事件触发时：
  1. 检测所有虚空印记flag
  2. 按印记权重分配Boss候选池
  3. 从候选池中加权随机选择最终Boss
  4. 若无任何印记（极端情况），从全池纯随机
```

## 隐藏Boss机制

以下Boss需要特定flag组合才能解锁进入候选池，否则不会出现：

| Boss                              | 解锁条件                         |
|-----------------------------------|------------------------------|
| **扭曲意识**（warped_consciousness）    | 灵能印记 ≥ 3层 + 献祭印记 ≥ 2层        |
| **异次元传送门**（dimensional_portal_ed） | 献祭印记 ≥ 3层 + power_level ≥ 4级 |
| **虚境化身**（psionic_avatar）          | 灵能印记 ≥ 2层 + 触发过灵能事件          |
| **恶堕化身**（corrupted_avatar）        | 灵能印记 ≥ 3层 + 献祭印记 ≥ 3层        |
| **虚境显圣**（shroud_manifestation）    | 灵能印记 ≥ 4层（罕见隐藏）              |

隐藏Boss一旦解锁，在最终选择中拥有更高的基础权重，但需要玩家在游戏过程中有意识地朝某个方向积累印记才能见到。

## 事件流程

```
游戏进程                          Boss系统
────────                         ────────
战斗杀敌         →  积累 战痕印记
爆星             →  积累 毁灭印记
舰船被毁         →  积累 献祭印记
特殊事件选择     →  积累 灵能/污秽/古老印记
power_level提升  →  积累 科技印记
                                        ↓
                         缩圈至最后阶段 / power_level达标
                                        ↓
                        Boss降临事件触发
                          ↓
                    检测所有flag → 构建候选池 → 加权随机
                          ↓
                    生成Boss + 精英卫队
                          ↓
                    击杀 → 胜利
```

## 实现优先级

1. **第一阶段**：Boss降临事件后置 + flag积累框架 + 加权随机选择
2. **第二阶段**：印记分类完善 + 每个Boss对应印记绑定
3. **第三阶段**：隐藏Boss解锁条件 + 出现动画/警告差异化
4. **第四阶段**：Boss奖励差异化 + 虚空遗物掉落
