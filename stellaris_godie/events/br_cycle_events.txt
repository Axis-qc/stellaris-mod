# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Scope: country (br_void_country)
# 触发源: br.250末尾周目分支（接入时需改动br.250）
# 作用: 复用br.700选出生点、传送玩家、排程定时器、叠敌军buff、重启刷敌
# 注意: br.700的br.701部分在多周目时自然跳过（玩家已是br_player_pve类型）
country_event = {
    id = br.955
    hide_window = yes
    is_triggered_only = yes

    immediate = {
        # 复用br.700选出生点（br_player_spawns_marked已在br.952清除）
        country_event = { id = br.700 }

        # 传送所有玩家舰队到新出生点（分散到6个出生点）
        every_country = {
            limit = { is_country_type = br_player_pve }
            every_owned_fleet = {
                random_list = {
                    1 = {
                        set_location = { target = event_target:br_player_spawn_system_1 distance = 30 angle = random }
                    }
                    1 = {
                        set_location = { target = event_target:br_player_spawn_system_2 distance = 30 angle = random }
                    }
                    1 = {
                        set_location = { target = event_target:br_player_spawn_system_3 distance = 30 angle = random }
                    }
                    1 = {
                        set_location = { target = event_target:br_player_spawn_system_4 distance = 30 angle = random }
                    }
                    1 = {
                        set_location = { target = event_target:br_player_spawn_system_5 distance = 30 angle = random }
                    }
                    1 = {
                        set_location = { target = event_target:br_player_spawn_system_6 distance = 30 angle = random }
                    }
                }
            }
        }

        # 给敌军国家叠加一层周目强度buff（永久，可叠加）
        event_target:br_pve_enemy_country = {
            add_modifier = {
                modifier = br_cycle_strength_buff
                days = -1
            }
        }

		# 设置缩圈暂停flag，1800天后由br.957解除并启动缩圈/伤害
		set_global_flag = br_shrink_paused
		country_event = { id = br.957 days = 1800 }

		remove_global_flag = br_cycle_resetting

        # 清除刷敌进度标记，让外圈杂兵（br.820-823）和内圈（br.801-813）重新刷出
