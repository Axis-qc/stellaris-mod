# 数值由事件层 mult = value:lev_support_* 动态决定，字段写单位值

# 且离轨清理/月度兜底需要按名字区分「永续」与「定时」。
# 主动版施加时同步 set_timed_planet_flag（lev_support_active_flag，3600 天），
# 月度兜底见此标记即跳过，保证定时 buff 走完整周期。
# 图标复用原版行星 modifier 图标，不需要自绘。
