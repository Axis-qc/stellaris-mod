# 利维坦技能数值 — 强度动态跟随成长等级（每级 +10% 基准，整数制）
# ============================================
# 先锋舰/行星支援同构：script_value 出整数百分比（或点数），事件层
# add_modifier 的 mult = root.owner.value:<名字>，modifier 字段写单位值
# （0.01 = 每 1 点数值 +1%，闪避等点数字段写 1）。
# 本地化由 scripted_loc/lev_skill_loc.txt 的 defined_text 暴露同名 token，
# 按钮 tooltip 动态显示真实数值。等级 0 = 原 V1 面板值，10 级约翻倍。
#
# script_value 的 add 只接受值表达式，不接受嵌套块（插件校验口径），
# 因此每维度拆两级：<名字>_step = { base = 0 add = owner.lev_<T>_growth_level
# mult = <每级增量> }，主值 = { base = <V1基准> add = value:<step名> }。
# step = V1 基准 × 0.1 四舍五入（35→4、25→3、30→3、50→5、20→2）。
# 敌方 debuff 的 modifier 描述在敌方作用域无法读施放者变量，动态数值
# 只在施放方的按钮 tooltip 展示，敌方身上的 modifier 描述用定性文案。
# 增益/减益数值一律存正幅度，方向由 modifier 字段符号决定。
#
# 噬星者只强化恒星光束（吞噬/重燃恒星是 D1-D6 拍板的核心机制，不动）。
