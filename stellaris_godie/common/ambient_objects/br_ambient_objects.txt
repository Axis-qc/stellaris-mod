# create_ambient_object 使用要点
#   - entity 来自 .asset，ambient_object 只是给它套名字；type = 本文件的 name
#   - location 用 ship/planet/star（fleet 无 3D 坐标会不可见）；use_3d_location 决定 3D/2D
#   - 星球位物体要 entity_scale_to_size = yes + scale（否则不会跟星球缩放）
#   - 朝向：base_angle_towards / entity_face_object（不写就按系统平面摆）
#   - beam 类：entity_scale_to_size = yes + scripted_scale（不能用 scale）；location=起点，entity_face_object=终点
#   - duration = 存活天数；play_animation_once = yes 只播一次
# 参考：原版 paragon_events.txt paragon.250（船->星球光束）；本项目 heroship.1200
