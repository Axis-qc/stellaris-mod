# 利维坦成长值系统 — 舰队状态栏显示
# ============================================
# 配合 ship_size 的 custom_state_loc_prefix = "LEV_STELLARITE_STATE"。
#
# 作用域：选中的舰队，owner.<变量> 读国家级成长数据。
#
# 文件前半按利维坦分组，每组四条，语义各组相同：
#   GetLevStateLevel<TYPE>   成长等级
#   GetLevStateGrowth<TYPE>  当前成长值
#   GetLevStateNext<TYPE>    下一级所需成长值
#   GetLevStateFeed<TYPE>    当前档位名义月收益（档位为「停止」时为 0）
# 新增一只利维坦：照抄一组加末尾一行，把 TYPE 与底层变量名换成该利维坦的即可。
# 本地化侧对应键为 LEV_<TYPE>_STATE_title / _value / _tt。
