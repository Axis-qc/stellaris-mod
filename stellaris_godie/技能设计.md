# 群星：大逃杀模式 — 英雄舰核心技能早期设计文档（含数值）

> 当前文档用于整理「挑战虚空 / 大逃杀模式」中的英雄舰核心、技能组、等级成长与设计约束。
> 重点区分：**母舰负责造船与补给，英雄舰负责战斗流派与技能构筑。**

---

# 一、系统定位

## 1.1 母舰与英雄舰分工

### 母舰

母舰是玩家的战略基地与后勤核心。

主要职责：

* 造船
* 补给
* 资源转化
* 战斗支援
* 玩家基础生存保障
* 作为玩家的移动后方

母舰不承担主要流派构筑职责。

### 英雄舰

英雄舰是玩家的战斗流派核心。

主要职责：

* 选择核心类型
* 决定战斗风格
* 搭载主动技能、被动技能和大招
* 通过独立等级系统成长
* 在 PvE 推进和 Boss 战中发挥关键作用

英雄舰不是母舰。
母舰负责“生产与补给”，英雄舰负责“战斗与构筑”。

# 二、英雄舰核心系统总规则

## 2.1 核心选择

每个玩家只能选择 **1 个英雄舰核心**。

核心决定英雄舰的主要玩法方向。

## 2.2 技能选择

每个核心内，玩家选择：

* **1 个主动技能**
* **1 个被动技能**
* **1 个大招**

技能组用于在同一核心内部形成不同构筑。

## 2.3 英雄舰等级系统

每个玩家的英雄舰拥有独立等级系统。

英雄舰**无最高等级限制**。12 级后每获得 2000 XP 再升 1 级（每级 XP 需求固定为 2000）。

每个玩家的英雄舰等级独立计算，不共享。

## 2.4 英雄舰经验建议

经验来源建议：

* 击毁普通敌舰：+1 XP
* 击毁精英敌舰：+5 XP
* 击败精英舰队：+20 XP
* 爆破普通星球：+10 XP
* 爆破高价值星球：+25 XP
* 完成随机事件：+10～30 XP
* Boss 阶段推进：+50 XP
* 击败最终 Boss：+200 XP

## 2.5 经验曲线

| 英雄舰等级 | 所需累计 XP | 阶段定位   |
|-------|--------:|--------|
| 1     |       0 | 初始     |
| 2     |      20 | 基础成长   |
| 3     |      50 | 主动技能强化 |
| 4     |      90 | 基础属性强化 |
| 5     |     140 | 流派展开   |
| 6     |     200 | 被动技能强化 |
| 7     |     280 | 中期成长   |
| 8     |     370 | 高阶构筑   |
| 9     |     470 | 大招强化   |
| 10    |     600 | 终局准备   |
| 11    |     760 | 终局强化   |
| 12    |     950 | 核心终极形态 |
| 12+   | +2000/级 | 无限成长（每级固定 2000 XP）|

## 2.6 通用等级属性成长

每升 1 级，英雄舰获得：

* 船体值：+3%
* 护甲值：+3%
* 护盾值：+3%
* 武器伤害：+1.5%

所有数值为乘算叠加（`ship_hull_mult` 等 modifier），随等级线性无上限增长。

核心专属技能强化另算。

### 2.6.1 技能倍率与持续时间

所有技能效果受两套倍率同时放大（代码 `heroship_level_events.txt:164-175`）：

```
br_skill_N_mult_player = hero_level × 0.1   → 最终效果倍率 = 1 + level × 0.1
br_skill_N_daymult_player = hero_level × 0.1 → 最终持续时间倍率 = 1 + level × 0.1
```

**效果倍率**（`mult`）放大 modifier 数值；**持续时间倍率**（`time_multiplier/daymult`）放大技能持续天数。两者独立且均为线性无上限。

例：Lv12 时倍率 = ×2.2，Lv50 时倍率 = ×6.0。

# 三、设计约束

## 3.1 危险区限制

危险区是星系级状态，只有两种情况：

* 是危险区
* 不是危险区

危险区相关技能只能作为：

* 撤离
* 保命
* 临时减伤
* 紧急赶路

不设计长期顶毒流。

## 3.2 缩圈机制限制

缩圈路线在开局扩圈时已经固定，后续只是反向收缩。

不设计：

* 预测下一阶段安全区方向
* 显示未来圈路线
* 改变缩圈路线
* 临时改变安全区中心

## 3.3 奖励机制限制

奖励通常在事件触发时随机生成，不天然存在“下一次奖励”。

不设计：

* 提前查看下一次奖励
* 预言未来奖励
* 直接锁定尚未生成的奖励

允许设计：

* 当前奖励重抽
* 当前奖励额外选项
* 提高某类奖励权重
* 获得一次额外奖励

# 五、火力核心（Power）— 输出 / 爆发向

## 核心定位

火力核心专注于英雄舰自身火力输出与友军火力加成。选火力就是选"打得更狠"——通过主动易伤、自强化、战斗叠层和爆发窗口，在战场上造成毁灭性伤害。

## 技能选择

* Lv2（主动×2选1）：能量超频 / 弱点扫描
* Lv4（被动×2选1）：战意过载 / 越战越勇
* Lv6（大招×2选1）：火力全开 / 终末齐射

玩家共组成 **8 种技能组合**，每种组合均有对应的联动效果。

---

## 主动技能

### 能量超频（Energy Overcharge）
**文件**：`events/heroship_skill_power_events.txt:1100`  
**modifier**：`br_vanguard_power_energy_overclock` → `ship_fire_rate_mult = 0.4` + `ship_hull_regen_add_perc = -0.01`

- 英雄舰射速 **+40%**，**降低每日船体回复** `-0.01`（被核心组件自带 `+0.01×level` 回血覆盖，任何等级不掉血）
- 持续 **10 天**（受 daymult 放大），冷却 **90 天**
- 效果受 `br_hero_ship_skill_1_mult` 倍率强化，持续时间受 `br_hero_ship_skill_1_daymult` 倍率强化

### 弱点扫描（Weakness Scan）
**文件**：`events/heroship_skill_power_events.txt:1101`  
**modifier**：`br_vanguard_power_weakness_scan` → `ship_damage_reduction_mult = -0.30`

- 标记本星系所有敌方舰队，使其受到武器伤害 **+30%**
- 持续 **15 天**，冷却 **120 天**
- 所有效果受 `br_hero_ship_skill_1_mult` 倍率强化，每级+10%

## 被动技能

### 战意过载（Combat Stack）— 友方光环
**文件**：`events/heroship_skill_power_events.txt:1103-1104`  
**modifier**：`br_vanguard_power_combat_stack_damage` → `ship_weapon_damage = 0.02`

- 战斗中 **每日+1 层**，每层武器伤害 **+2%**
- 上限 **50 + 英雄等级**（代码 `br_vanguard_combat_stack_cap`，与越战越勇共用上限逻辑）
- **星系内所有非敌方舰队共享**该加成
- 每层伤害受 `br_hero_ship_skill_2_mult` 倍率强化，持续时间受 `br_hero_ship_skill_2_daymult` 倍率强化

### 越战越勇（Kill Stack）
**文件**：`events/heroship_skill_power_events.txt:1102`  
**modifier**：`br_vanguard_power_kill_stack_damage` → `ship_weapon_damage = 0.01`

- 每击杀 1 艘敌舰获得本局永久武器伤害 **+1%**
- 上限 **50 + 英雄等级**（例：12级时上限 62 层）
- 每层伤害受 `br_hero_ship_skill_2_mult` 倍率强化，每级+10%

## 技能联动系统

### 设计原则

- **不改架构**：只在已有事件内加条件判断，不新增事件、modifier 或 flag 管理系统
- **只联被动↔大招**：被动是持续生效的，大招是爆发窗口的，两者联动自然且实现简单
- **联动统一由大招激活flag触发**：大招激活时设一个简单的 country flag，被动 tick 事件检测该 flag 即可

### 联动链A — 战意↔大招（改 `heroship.1104` 战意每日tick）

**触发条件**：选了战意过载 + 任一火力大招（火力全开 / 终末齐射）

- **通用效果**：大招激活期间，战意叠加速度 **翻倍**（每日 +2 层）
- **火力全开专属**：大招结束时保留 **30%** 当前战意层数，不清空
- **终末齐射专属**：终末期间每层战意额外给英雄舰自身提供 **+0.5%** 射速（用 `ship_fire_rate_mult` modifier 实现，`mult = br_vanguard_power_combat_stack × 0.005`）

**代码改动**（仅 heroship.1104 约+5行）：
```pseudocode
# 战意tick内，检测大招flag
if owner.has_country_flag = br_vanguard_ultimate_active
    change_variable战意 +2
else
    change_variable战意 +1

# 火力全开专属：结束时保留30%
if has_modifier = br_vanguard_power_ultimate_fullfire
    # 正常结束时不清空，保留30%
```

### 联动链B — 越战↔大招（改 `heroship.1102` 越战击杀触发）

**触发条件**：选了越战越勇 + 任一火力大招

- **通用效果**：大招激活期间，击杀获得的越战层数 **翻倍**（+2 层/击杀）
- **火力全开专属**：击杀得 **3 倍** 层数（+3 层/击杀）
- **终末齐射专属**：终末期间越战对英雄舰自身的武器伤害加成 **翻倍**（50 层 = 平时 +50%，终末期间 +100%）

**代码改动**（仅 heroship.1102 约+5行）：
```pseudocode
# 越战叠加时，检测大招flag
if owner.has_country_flag = br_vanguard_ultimate_active
    if has_country_flag = br_skill_fullfire_unlocked
        change_variable +3
    else
        change_variable +2
else
    change_variable +1

# 终末齐射期间自加成翻倍：在施加modifier时，将br_vanguard_kill_buff ×2
```

# 六、防御核心（Defense）— 生存 / 承伤 / 修复向

## 核心定位

防御核心专注于舰队存活、伤害吸收和战损修复。既能硬扛伤害，也能快速恢复战斗力。

## 主动技能

### 防御协议 — 自身坦克 + 团队再生
英雄舰自身获得减伤（10% × sk1_mult）+ 嘲讽，武器伤害 -100%；同时星系内友方获得每日船体/护甲/护盾再生（20% × sk1_mult）。统一持续 5 天（受 daymult 强化）。冷却 240 天。

### 协同防御协议 — 牺牲保队友
大幅提升英雄舰自身船体 / 护甲 / 护盾上限 + 高额每日再生，持续 15 天（受 daymult 强化）。冷却 150 天。

数值：`ship_hull_mult / ship_armor_mult / ship_shield_mult = X` + `ship_hull_regen_add_perc / ship_armor_regen_add_perc / ship_shield_regen_add_perc = Y`，受 `br_hero_ship_skill_1_mult` 倍率强化。

## 被动技能

### 结构增幅 — 自身增幅
**公式：`300 × 英雄等级 × br_hero_ship_skill_2_mult`**
英雄舰自身获得船体/护甲/护盾 + 此数值。英雄舰等级越高，身板越硬。

Lv1: 300 × 1 × 1.1 = **330**
Lv5: 300 × 5 × 1.5 = **2250**
Lv10: 300 × 10 × 2.0 = **6000**

### 协同结构力场 — 团队增幅
**公式：`100 × 英雄等级 × br_hero_ship_skill_2_mult`**
本星系内友方舰船获得船体/护甲/护盾 + 此数值。

Lv1: 100 × 1 × 1.1 = **110**
Lv5: 100 × 5 × 1.5 = **750**
Lv10: 100 × 10 × 2.0 = **2000**

### 实现方式
- modifier：`br_vanguard_def_structure`（自身，永久） / `br_vanguard_def_field`（光环，days=31 循环刷新）
- 两个 modifier 数值写 1，通过 `mult = script_value` 缩放
- 新增 script_value：`br_vanguard_def_structure_mult` / `br_vanguard_def_field_mult`
- 光环每 30 天由事件 `heroship.1203→1204 循环` 刷新一次

## 大招（Lv6 二选一）

### 维度坍塌 — 自身爆发
**公式：消耗总三维 × 50% → 对本星系所有敌方舰船造成等量船体伤害**
英雄舰将自身船体/护甲/护盾总值的 50% 转化为毁灭性能量释放，直接对星系内所有敌方舰船造成等量船体伤害。

Lv1（假设总三维约5000）：消耗2500 → 对每艘敌舰造成 **2500** 船体伤害
Lv10（假设总三维约30000）：消耗15000 → 对每艘敌舰造成 **15000** 船体伤害

**实现**：
- `export_trigger_value_to_variable` 读取 `has_max_hp` + `has_max_armor_hp` + `has_shield_hp` 求和
- 乘 0.5 → 设为伤害变量
- `damage = { hull = value:br_ultimate_damage }` 对星系每个敌方舰队执行
- 冷却 **240 天**

### 维度结构投影 — 团队增幅
**公式：总三维 × 10% → 星系友方船体/护甲/护盾各 + 此数值**
英雄舰将自身结构完整性投射到星系友方舰船上，为其提供额外船体/护甲/护盾。

Lv1（总三维约5000）：友方三维各 +**500**
Lv10（总三维约30000）：友方三维各 +**3000**

**实现**：
- `export_trigger_value_to_variable` 读取总三维
- 乘 0.10 → 设为 buff 变量
- `add_modifier` 友方舰队 modifier（`ship_hull_add / ship_armor_add / ship_shield_add = 1`，`mult = value:br_ultimate_buff`）
- 持续 **20 天**，冷却 **360 天**
- 所有效果受 `br_hero_ship_skill_3_mult` 倍率强化

## 废弃栏

以下为精简过程中淘汰的技能组，保留作参考。

> 等级强化系统（各技能的 3/6/9/12 级独立强化节点）已整体废弃。
> 新版改为英雄等级直接线性提升所有技能效果与持续时间，不再为单个技能设独立强化节点。

### 主动（废弃）

* **协同防御协议（旧）**：本系统友军护盾 +50%，脱离概率 +50%，持续 25 天。冷却 150 天。
* **紧急修复矩阵**：立即修复本系统友军 35% 船体、35% 护甲、35% 护盾。冷却 180 天。
* **装甲展开**：本系统友军护甲 +60%，船体 +25%，持续 20 天。冷却 150 天。
* **维修信标**：部署 45 天维修信标，本系统友军每日回复 1.5% 船体。冷却 180 天。
* **危险撤离协议**：如果舰队位于危险区，移动速度 +150%，受到伤害 -50%，持续 15 天。冷却 240 天。

### 被动（废弃）

* **紧急稳定器**：英雄舰受到致命伤害时保留 10% 船体，并获得 5 天伤害减免 50%。冷却 360 天。每场战斗限 1 次。
* **防线核心**：英雄舰存活时，本系统友军受到伤害 -10%。
* **不屈**：英雄舰船体低于 20% 时，护盾 +50%，护甲 +50%，脱离概率 +100%，持续 15 天。每场战斗限 1 次。
* **护盾充能**：脱战后英雄舰每日恢复 5% 护盾。
* **共生护甲**：英雄舰击杀敌舰后回复 2% 船体和 2% 护甲。
* **维修光环**：英雄舰所在系统友军每日回复 0.5% 船体。

### 大招（废弃）

* **虚空锚点**：部署 60 天锚点；期间英雄舰被毁后在锚点处重生并回复 50% 船体。冷却 480 天。

* **终局借贷**：Boss 战期间伤害 +200%，射速 +100%，持续 360 天；若期间击败 Boss，则免除债务；若失败，伤害 -150%，持续 1800 天。冷却
  9999 天。

# 十四、指挥核心（Command）— 战术指令 / 协同作战 / 队伍增益向

## 核心定位

指挥核心专注于战术指令与多舰队协同。不直接获取资源或操控奖励，而是通过精准的战场指挥让友军发挥更高战斗力。舰队越多，指挥优势越大。

## 主动技能

* **战术指令：攻击**：本系统友军伤害 +25%，射速 +15%，持续 25 天。冷却 120 天。
* **战术指令：防御**：本系统友军护盾 +30%，护甲 +30%，脱离概率 +50%，持续 25 天。冷却 120 天。
* **战术指令：机动**：本系统友军速度 +75%，闪避 +20，持续 25 天。冷却 120 天。
* **目标解析**：标记本系统敌方主力，使其受到伤害 +20%，持续 25 天。冷却 150 天。
* **战术重组**：本系统友军获得射速 +20%、闪避 +15，持续 15 天；若本系统有至少 3 支友军舰队，额外获得武器伤害 +15%。冷却 150 天。

    * 3 级强化：射速提高到 +25%。
    * 9 级强化：额外触发门槛降低到 2 支舰队。

## 被动技能

* **协同火控**：本系统每 10 艘友军舰船提供命中 +1，追踪 +1，上限 +15。

    * 6 级强化：上限提高到 +20。

    * 6 级强化：上限提高到 +15。

* **战术积累**：每完成事件或击败精英获得 1 层战术层数，每层使战术指令效果 +3%，上限 10 层。

    * 6 级强化：加成提高到 +8%。

# 十六、总结

母舰负责生产、补给和战略后勤。
英雄舰负责战斗技能、核心选择和个人成长。

每个玩家拥有独立英雄舰等级，最高 12 级。
每个玩家选择一个核心，并在该核心内选择 1 主动、1 被动、1 大招。
通过等级成长、资源奖励和战斗推进，英雄舰逐渐形成独特流派。

核心分工原则：
* 火力核心 — 杀得快（攻击向）
* 防御核心 — 活得久 + 修得回（生存+修复向）
* 支援核心 — 造得快、船更多（补员+生产向）
* 掠夺核心 — 以战养战、侵略性资源获取（资源掠夺向）
* 指挥核心 — 多舰队协同作战（战术增益向）
* 其余核心 — 各自独立玩法方向

该系统的目标是让「挑战虚空」不仅是缩圈与 Boss 战，而是一个具有 Roguelike 构筑感的舰队成长模式。

## 17.5 需要特殊处理的机制

### 17.5.1 复制体 — 无法完全复制英雄舰状态

`clone_leader` 仅适用于领袖。英雄舰是舰船，无法完全复制：

- ✅ 可以：创建相同 ship design 的舰船
- ❌ 不可以：复制当前 modifier 状态、变量层数、当前血量百分比
- 建议：创建同 design 的新英雄舰 + 施加预设的 "复制体" modifier（`ship_hull_mult = -0.5` + `ship_weapon_damage = -0.5`）。注：复制体已从支援核心移除，仅在献祭核心中保留类似概念。

### 17.5.2 冷却减少 — scripted_action cooldown 无法运行时修改

`scripted_action` 的 `cooldown = N` 是静态定义，无法在运行时动态修改。替代方案：

- **方案A**：使用充能系统（charges）代替冷却。通过事件添加充能来模拟"冷却减少"。
- **方案B**：不在 scripted_action 层面处理冷却，而是在事件层面用 country flag + 延迟事件手动管理冷却。杀敌时取消当前冷却事件并设置更短的延迟。
- 推荐方案B用于"热能回收"和"血债充能"。

### 17.5.3 舰体熔铸 — 永久叠层 modifier 实现

每层提供 `ship_hull_mult = 0.01` + `ship_armor_mult = 0.01`，上限 50 层：

- **方案A**：创建 50 个独立的 modifier（如 `br_ship_forge_01` 到 `br_ship_forge_50`），根据层数变量施加/移除。缺点：modifier
  数量多。
- **方案B**：使用单一 modifier + `mult = variable`。每次献祭后 `change_variable`，modifier 使用 `mult = br_forge_stack`
  。优点：只需一个 modifier。
- 推荐方案B。50层上限完全可控。

### 17.5.4 债务时间减少 — 延迟事件时间无法动态修改

"提前偿还"和"利息转嫁"需要"减少债务持续时间"：

- 延迟事件（`country_event = { days = 1800 }`）一旦设定，无法修改。
- **方案A**：不修改已有的延迟事件，而是提前触发清除效果并取消原延迟事件（通过 flag 门控）。
- **方案B**：使用每日 on_action 计数债务剩余天数，击杀时减少计数。
- 推荐方案A：在杀敌事件中检测是否已到"还债"状态，如果是则提前清除负面并取消延迟事件。

### 17.5.5 飞弹齐射 — 需要敌方 scope

`damage_ship` 作用于当前 scope 内的舰船。要伤害"本系统随机 5 个敌方目标"：

- 需要能 scope 到敌方舰船。在战斗中可通过 `any_enemy_ship` 或 `random_enemy` scope（需验证是否存在）。
- 替代方案：使用星系级光环效果 + `ship_hull_regen_add_perc` 负值作为"持续伤害"近似，或通过伤害事件对星系内所有非友方舰船造成伤害。
- 建议：在 mod 开发中优先验证 `random_enemy_ship` scope 是否存在。

### 17.5.6 高速机动 — 速度转闪避无法直接换算

"舰队速度加成每有 +50%，获得闪避 +5"无法用简单的 modifier 实现，因为无法读取当前速度倍率值。

- 替代方案：将设计改为"当舰队速度达到阈值时获得额外闪避"，即预设速度挡位检查条件：
    - `ship_speed_mult >= 0.5` → `ship_evasion_add = 5`
    - `ship_speed_mult >= 1.0` → `ship_evasion_add = 10`
    - (以此类推)
- 或简化为固定值："速度被强化时，闪避 +X"

## 17.7 推荐实现次序（基于可行性）

所有核心的机制均可行或可通过已知方案实现。推荐次序与第十七章一致：

**第一批**（机制最简单、依赖最少）：

- 火力核心：仅需基础战斗 modifier + damage 事件
- 防御核心：防御 modifier + repair 命令 + 维修光环
- 支援核心：create_fleet + 循环事件 + 经济条件判断
- 命运核心：延迟事件 + modifier 切换

**第二批**（需要多层计数或特殊逻辑）：

- 献祭核心：需要 destroy_ship 循环（注意性能）
- 机动核心：需要星系进入钩子检测
- 控制核心：需要光环组件支持
- 掠夺核心：需要与经济系统整合

**第三批**（依赖武器类型 modifier + 生成管理）：

- 航母核心：create_fleet 批量管理 + weapon_type modifier
- 指挥核心：需要奖励系统 API 支持（如重抽、额外选项）
